# Навык: sync_and_verify (Синхронизация и прямая верификация)

Используйте этот навык после любых изменений в переводах (`translations/`), чтобы гарантировать применение в игре и исключить ложные подтверждения.

## Порядок выполнения

1. **Применение правок**:
   - Выполнить локальный скрипт задачи: `python tasks/<task_name>/scripts/apply_and_sync.py`
   - Или общую синхронизацию: `node sync_all_to_game.js`

2. **Прямая верификация физического файла игры**:
   - Запустить скрипт проверки:
     ```powershell
     python tools/verify_keys.py <namespace> <key1> <key2> ...
     ```
   - Убедиться, что файл `D:\ModrinthApp\profiles\Society_ Sunlit Valley\kubejs\assets\<namespace>\lang\ru_ru.json` содержит актуальные значения.

3. **Проверка отсутствия дубликатов скриптов KubeJS**:
   - При добавлении или обновлении скриптов в `client_scripts/tooltips/` или `server_scripts/` проверить, что старые копии скриптов в корневых директориях отсутствуют (KubeJS загружает скрипты рекурсивно).

4. **Отчёт пользователю**:
   - Вывести фактические значения проверенных ключей в ответе.
   - Подсказать точный способ перезагрузки:
     - Обычный текст / тултип / диалог: **`F3 + T`**
     - Квесты FTB Quests: **`F3 + T`** + `/ftbquests reload`
     - Рецепты / JEI: **перезапуск клиента**.
