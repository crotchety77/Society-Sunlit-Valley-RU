## 1. 🏗️ Суть механики, крафт и интерфейс

**Станция ремесла (`Craft Station`)** — это универсальная фабричная машина сборки. Она заменяет собой печи, дробители Create, пилорамы, алхимические котлы, бочки маринования и кристаллариумы. Каждое ремесло строго привязано к **Стихийному типу покемона (Elemental Type)** и его характеристикам.

### Рецепт крафта (`craft_station.json`):
* **Верхний ряд:** `Железный слиток` | `Железный слиток` | `Железный слиток`
* **Средний ряд:** `Железный слиток` | `Покебол (Poke Ball)` | `Железный слиток`
* **Нижний ряд:** `Гладкий камень` | *пусто* | `Гладкий камень`

```
[ 🪙 ]   [ 🪙 ]   [ 🪙 ]
[ 🪙 ]   [ 🔴 ]   [ 🪙 ]
[ 🪨 ]   [    ]   [ 🪨 ]
```

### Интерфейс:
1. **Слот сырья (Input):** Загрузка ингредиента вручную или через воронку сверху/сзади.
2. **Слот результата (Output):** Выгрузка готовой продукции в сундук или воронку снизу.
3. **Слот покемона:** Помещается покемон соответствующей стихии.
4. **Индикатор прогресса и кнопка приоритета:** Отображает расчётное время и множитель дропа.

## 2. 🧠 Формулы и математика (Реверс-инжиниринг байткода)

### А. ⚡ Множитель скорости крафта (`SpeedModifier`):
$$\text{SpeedModifier} = \left(\frac{\lfloor (\text{SpeedStat} / 127.5) \times 100 \rfloor}{100}\right) \times (\text{isShiny ? } 2.0 : 1.0)$$
$$\text{Итоговое время крафта (в секундах)} = \frac{\text{BaseCraftingTime (в тиках)}}{20 \times (\text{SpeedModifier} + \text{BonusSpeed})}$$

* При стате 128 $\rightarrow 1.0\times$ скорости.
* При стате 255 $\rightarrow 2.0\times$ (время сокращается вдвое).
* 🔴 **Шайни-бонус:** Увеличивает множитель до **$4.0\times$** (крафт в 4 раза быстрее).

---

### Б. 🎁 Математика мульти-дропа (`MultChance`):

В байткоде `processRecipe` реализован каскадный алгоритм умножения продукции:

$$\text{MultChance (\%)} = \lfloor (\text{MultStat} / 127.5) \times 100 \rfloor \times (\text{isShiny ? } 2 : 1)$$

```java
int totalMultiplier = 1;
int remainingChance = multChance;
while (remainingChance > 0) {
    if (random.nextDouble() * 100.0 < Math.min(remainingChance, 100)) {
        totalMultiplier++;
    }
    remainingChance -= 100;
}
```

* При стате 128 $\rightarrow \text{MultChance} = 100\%$ (**гарантированный x2 дроп**).
* При стате 255 $\rightarrow \text{MultChance} = 200\%$ (**гарантированный x3 дроп!**).
* 🔴 **Шайни-бонус:** Разгоняет шанс до $400\%$, давая **гарантированный x5 дроп** готовой продукции!

## 4. 🔄 Автоматизация и синергии базы

```
  [ Саженцы с фермы ягод / сада ] ──► [ Craft Station (Fighting: Attack + Sp.Def) ]
                                                       │
                                        (1 Саженец ──► 4-12 Брёвен)
                                                       │
                                                       ▼
  [ Печь / Пилон энергии (+50% Speed) ] ◄── [ Выгрузка брёвен в Сундук базы ]
```

### 🔥 Топовые связки и эксплойты Станции ремесла:
1. **Связка «Бесконечная древесина из саженцев»:**
   Поставьте покемона типа *Fighting* со статами $\text{Atk} \ge 250$ и $\text{Sp.Def} \ge 250$ (*Lucario / Urshifu*). Подавайте избыточные саженцы через воронку — за 3–6 секунд станция выдаёт от **4 до 12 брёвен** из 1 саженца!
2. **Связка «Поке-Кристаллариум»:**
   Поместите покемона типа *Ice* с высоким $HP$ и $Sp.Atk$ (*Lapras / Walrein*). Станция непрерывно размножает редкие минералы, алмазы и призматические кристаллы без расхода исходного образца.
3. **Связка «Разгон Пилоном со Спектральной батареей»:**
   Установите рядом `Energy Pylon` со `Spectral Battery` ($+2.0\times$ к скорости). Станция ремесла начнёт плавить металлы и перерабатывать руды со скоростью **в 5–6 раз быстрее обычной печи**!

🌟 Главные механические открытия по Ремеслу:
Каскадная формула мульти-дропа: При стате 128 выдаётся гарантированный $x2$ дроп, при стате 255 — гарантированный $x3$ дроп, а у Шайни — вплоть до $x5$ продукции за цикл!
Пилорама из саженцев (Fighting): 1 любой саженец (дуб, вишня, априкорны) перерабатывается в 4–12 брёвен всего за 3–6 секунд (статы Attack + Sp.Def).
Кристаллариум (Ice): Ледяные покемоны (Lapras, Walrein, Avalugg) бесконечно дублируют кристаллы и минералы.
Супер-плавка (Fire): Плавит руду и пищу в 2 раза быстрее ванильной печи (без расхода угля!).
Генная инженерия (Psychic): Переработка выдержанного древнего сидра в Поке-гены (Poke Genes) для создания Mewtwo.
Алхимия смузи (Bug): Варка зелий лечения из ягодных смузи (Defence).
