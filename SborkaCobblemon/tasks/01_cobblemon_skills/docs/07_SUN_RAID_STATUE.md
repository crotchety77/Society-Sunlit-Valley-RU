# ☀️ Статуя Солнечного Рейда (Sun Raid Statue)

> **Мод / Исходники:** `sunlit_cobblemon` + `kubejs/server_scripts/cobblemon/cobblemonRaid.js`  
> **Предмет / Блок:** `sunlit_cobblemon:sun_raid_statue`  
> **Статус проверки:** 🟢 100% подтверждено кодом серверных скриптов KubeJS

---

## 1. 🏗️ Суть механики, крафт и интерфейс

**Статуя Солнечного Рейда (`Sun Raid Statue`)** — это центральный боевой алтарь сборки. Она позволяет игрокам запускать ежедневные рейдовые босс-файты, фармить ультра-редких покемонов с повышенным шансом Шайни (`Shiny`) и Скрытыми способностями (`Hidden Ability`), а также призывать великих Легендарных покемонов (*Xerneas, Yveltal, Pecharunt*).

### Интерфейс и взаимодействие:
1. **ПКМ (без Shift):** Выводит в чат подробную сводку текущего рейда (Тир сложности, вид покемона, расчётный уровень, шанс Шайни и шанс Hidden Ability).
2. **Shift + ПКМ (пустая рука):** Начинает битву с боссом (если рейд сегодня ещё не проводился).
3. **Shift + ПКМ (если рейд уже пройден):** Открывает магазин солнечных подношений (`sun_offering`).

## 2. 🧠 Формулы и математика (Реверс-инжиниринг KubeJS)

### А. 📊 Уровни сложности (Tiers 0–3) и шансы:

Сложность статуи определяет категорию редкости покемона, шанс Шайни и шанс Скрытой способности:

| Уровень сложности (Tier) | Категория пула покемонов (`bucket`) | Шанс Шайни (`ShinyChance`) | Шанс Скрытой способности (`HA Chance`) |
| :---: | :--- | :---: | :---: |
| **Tier 0 (Базовый)** | $50\%$ `common` / $50\%$ `uncommon` | $1 / 3584$ *(0.03%)* | $1 / 16$ *(6.25%)* |
| **Tier 1** | $25\%$ `rare` / $75\%$ `uncommon` | $1 / 3072$ *(0.03%)* | $1 / 16$ *(6.25%)* |
| **Tier 2** | $75\%$ `rare` / $25\%$ `uncommon` | $1 / 2560$ *(0.04%)* | $1 / 8$ *(12.50%)* |
| **Tier 3 (МАКСИМУМ)** | $25\%$ `ultra-rare` / $75\%$ `rare` | **$1 / 2048$** *(0.05%)* | 🔥 **$1 / 4$ (25.00%!)** |

---

### Б. 📈 Расчёт уровня рейдового босса (`RaidLevel`):

$$\text{RaidLevel} = \min\Big(100, \text{PartyLevel} + 5 \times (\text{Tier} + 1)\Big)$$

* Уровень босса динамически подстраивается под средний уровень команды игрока + получает надбавку за каждый тир сложности (+10 на Tier 1, +15 на Tier 2, +20 на Tier 3).
* 👥 **Кооперативный рейд:** Если рядом со статуей находится несколько игроков (радиус 10 блоков), уровень босса масштабируется по формуле группы (`sumMPRaidLevel`), и статуя призывает по одному усиленному боссу на каждого участника с интервалом в 1 секунду.

## 3. 🔮 Предметы управления Статуей и Призыв Легендарок

Статуя имеет уникальную систему модификации через специальные предметы:

| Предмет | Действие при клике ПКМ по Статуе | Как работает в коде |
| :--- | :--- | :--- |
| 🍪 **Печенье Мистики**<br>`sunlit_cobblemon:mystica_cookie` | **Переролл покемона** | Сбрасывает текущий вид покемона в статуе и генерирует нового из пула без изменения тира. |
| ☀️ **Эссенция Солнца**<br>`sunlit_cobblemon:sun_essence` | **Повышение Тира (+1 Tier)** | Повышает уровень сложности статуи (до Tier 3 MAX), открывая доступ к `ultra-rare` покемонам и 25% шансу HA. |
| 🪞 **Солнечное зеркало**<br>`sunlit_cobblemon:sun_mirror` | **Клонирование / Перенос** | 1-й клик: сохраняет покемона из статуи в зеркало. 2-й клик: записывает этого покемона в другую статую. |

---

### 👑 Призыв Легендарных покемонов (`sunLegendaries`):
Клик по статуе специальными реликварными предметами активирует эксклюзивный Легендарный рейд:

| Реликвия призыва | Призываемый Легендарный босс | Особенности |
| :--- | :---: | :--- |
| 💍 **Цветущее кольцо** (`sunlit_cobblemon:blooming_ring`) | 🌸 **Xerneas** | Легендарный олень жизни (Fairy). |
| 🏺 **Рог Изобилия Жадности** (`sunlit_cobblemon:cornucopia_of_greed`) | 🦅 **Yveltal** | Легендарный разрушитель (Dark / Flying). |
| 🐚 **Панцирь Печа** (`sunlit_cobblemon:pecha_shell`) | 🍑 **Pecharunt** | Мифический покемон повиновения (Poison / Ghost). |

## 4. 🔄 Тактика битвы, синергии и советы

1. **Фарм скрытых способностей (Hidden Ability 25%):**
   Всегда прокачивайте статус до **Tier 3** с помощью `Sun Essence`. Каждый четвёртый побеждённый покемон будет обладать редчайшей скрытой способностью (HA).
2. **Стратегия переролла с Печеньем Мистики:**
   Если статуя выбрала ненужного покемона, используйте `Mystica Cookie`, пока не выпадет желаемый редкий покемон (*Dratini, Beldum, Larvitar, Bagon, Gible*).
3. **Перк «Дикое Солнце» (`savage_sun`):**
   При открытии этапа `savage_sun` игрок получает **15% шанс не потратить дневной кулдаун рейда**, позволяя проводить несколько битв в одни сутки!
4. **Безопасная зона:** Статуя требует минимум 2 свободных блока воздуха над собой и отсутствие диких покемонов в радиусе 2 блоков для старта призыва.
