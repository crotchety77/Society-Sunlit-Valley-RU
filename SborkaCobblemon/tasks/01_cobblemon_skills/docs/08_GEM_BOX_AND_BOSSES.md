# 💎 Шкатулка самоцветов и Боссы Реджи (Gem Box & Regi-Titans)

> **Мод / Исходники:** `sunlit_cobblemon` + `kubejs/server_scripts/cobblemon/legendary/cobblemonGemBox.js`  
> **Предмет / Блок:** `sunlit_cobblemon:gem_box`  
> **Статус проверки:** 🟢 100% подтверждено серверным скриптом `cobblemonGemBox.js`

---

## 1. 🏗️ Суть механики, крафт и интерфейс

**Шкатулка самоцветов (`sunlit_cobblemon:gem_box`)** — это древний интерактивный алтарь-головоломка. С его помощью игрок решает комбинаторные загадки с 6 драгоценными камнями и активирует предмет **Чистая дощечка (`sunlit_cobblemon:tabula_rasa`)**, чтобы призвать легендарных титанов **100-го уровня**:
* 🪨 **Regirock** (Реджирок)
* ❄️ **Regice** (Реджиайс)
* ⚙️ **Registeel** (Реджистил)
* ⚡ **Regieleki** (Реджиэлеки)
* 🐉 **Regidrago** (Реджидраго)
* 👑 **Regigigas** (Реджигигас — верховный создатель титанов!)

### Рецепт крафта Шкатулки (`addCobblemonRecipes.js`):
* 4 Прочных камня (`quark:sturdy_stone`)
* 4 Чистые дощечки (`sunlit_cobblemon:tabula_rasa`)
* 1 Знак единства (`society:token_of_unity`)

### Получение Чистой дощечки (`tabula_rasa`):
* Производится на **Станции ремесла (`Craft Station`)** покемоном Каменного типа (`ROCK`):  
  **1 Призматический осколок (`society:prismatic_shard`) $\rightarrow$ 1 Чистая дощечка (`tabula_rasa`)**.

## 2. 🧠 Механика ритуала и правила ввода (Реверс-инжиниринг KubeJS)

### 🥽 Обязательное условие:
Для взаимодействия со Шкатулкой на лице игрока **обязательно должен быть надет Silph Scope (`sunlit_cobblemon:silph_scope`)**. Без него шкатулка не реагирует на клики.

### 💎 Набор 6 драгоценных камней:

| Код в скрипте | Драгоценный камень | ID предмета | Рыночная цена | Цвет спектра | Букв в названии |
| :---: | :--- | :--- | :---: | :---: | :---: |
| **`a`** | 🟣 Осколок аметиста | `society:amethyst_chunk` | Самый дешёвый | Фиолетовый | 13 букв (*AmethystChunk*) |
| **`q`** | 🔵 Аквамарин | `society:aquamarine` | Средняя | Голубой | 10 букв (*Aquamarine*) |
| **`t`** | 🟡 Топаз | `society:topaz` | Средняя | Жёлтый | 5 букв (*Topaz*) |
| **`r`** | 🔴 Рубин | `society:ruby` | Высокая | Красный | 4 буквы (*Ruby*) |
| **`j`** | 🟢 Нефрит (Жад) | `society:jade` | Высокая | Зелёный | 4 буквы (*Jade*) |
| **`s`** | 💖 Шпинель | `society:spinel` | Самый дорогой | Розовый | 6 букв (*Spinel*) |

### Алгоритм призыва:
1. Подойдите к установленной Шкатулке и поочерёдно кликните по ней **ПКМ 6 камнями** в строгом порядке комбинации.
2. Каждый верный камень сопровождается звуком щелчка и частицами.
3. Вставив 6-й камень, кликните по Шкатулке **ПКМ Чистой дощечкой (`tabula_rasa`)**.
4. Шкатулка поглощает дощечку, запускает 7 звуковых волн и призывает рейдового титана **100-го уровня**!

## 3. 🧩 Секретные комбинации призыва Реджи

Каждая комбинация построена на строгом логическом принципе:

```
1. 🪨 Regirock (По цене: Price)
   Аметист ──► Аквамарин ──► Топаз ──► Рубин ──► Нефрит ──► Шпинель
   (Код: a -> q -> t -> r -> j -> s)

2. ❄️ Regice (По спектру радуги: Rainbow)
   Рубин ──► Топаз ──► Нефрит ──► Аквамарин ──► Аметист ──► Шпинель
   (Код: r -> t -> j -> q -> a -> s)

3. ⚙️ Registeel (По размеру кристаллической решётки: Size)
   Аметист ──► Шпинель ──► Нефрит ──► Рубин ──► Топаз ──► Аквамарин
   (Код: a -> s -> j -> r -> t -> q)

4. ⚡ Regieleki (По числу букв в английском названии: Letter Count)
   Рубин ──► Нефрит ──► Топаз ──► Шпинель ──► Аквамарин ──► Аметист
   (Код: r -> j -> t -> s -> q -> a  или  j -> r -> t -> s -> q -> a)

5. 🐉 Regidrago (По алфавиту названий: Alphabetical)
   Amethyst ──► Aquamarine ──► Jade ──► Ruby ──► Spinel ──► Topaz
   (Код: a -> q -> j -> r -> s -> t)
```

## 4. 👑 Секрет Верховного Создателя: Призыв Regigigas

Чтобы призвать верховного **Реджигигаса 100-го уровня**:
1. Поймайте всех **5 малых титанов** (*Regirock, Regice, Registeel, Regieleki, Regidrago*).
2. Поместите всех 5 титанов в свою **активную команду (Party)**.
3. Активируйте Шкатулку самоцветов **любой правильной комбинацией** с помощью `tabula_rasa`.
4. Скрипт `cobblemonGemBox.js` проверит команду (`hasPartyPokemon`) и вместо малого титана призовет гигантского **Реджигигаса**!

🌟 **Главные механические открытия из кода:**
- **Очки Silph Scope обязательны** на голове игрока для взаимодействия со Шкатулкой.
- **5 независимых криптографических шифров** (цена, радуга, размер, длина слова, алфавит).
- **Реджигигас требует наличия всех 5 титанов в команде тренера** при финальной активации.
