# Рыбные пруды и Менеджер квестов (Fish Ponds & Manager)

> **Глубокий технический аудит системы прудов Stardew Valley в Society Sunlit Cobblemon**  
> *Содержит механику популяции (1..10), квесты на расширение, скип Зубом Потрошителя, скидки перков и синхронизацию с Create Clipboard.*

---

## 1. Суть блока, структура и популяция

**Рыбный пруд (`society:fish_pond`)** — аквакультурный блок, позволяющий разводить рыбу, получать икру (Roe), редкие сокровища и ценные ресурсы.

### 1.1. Базовые правила:
- **Заселение:** Правый клик рыбой (`#minecraft:fishes`) по пустому пруду заселяет первый экземпляр. Пруд принимает только один вид рыбы (попытка подселить другой вид блокируется ошибкой `cross_type_fish`).
- **Рост популяции:** Со временем рыба размножается от 1 до текущего лимита `max_population` (базово 1, 3 или 5 в зависимости от редкости рыбы).
- **Максимальный лимит:** Путём выполнения заданий рыбы лимит популяции расширяется до **10 особей**.

---

## 2. Механика квестов рыбы и скип Зубом Потрошителя

Когда популяция достигает промежуточного лимита, пруд переходит в состояние `quest = true` и над ним появляется восклицательный знак. Рыба просит принести определённые предметы для расширения среды обитания.

```javascript
// Проверка стоимости квеста и скидки этапа:
checkedCount = player.stages.has("pond_house_five")
  ? Math.round(questContent.count / 2)
  : questContent.count;
```

### 2.1. Скидка перка «Pond House V» (`pond_house_five`):
- При наличии этапа `pond_house_five` количество требуемых предметов для квеста рыбы **снижается на 50%** (`Math.round(count / 2)`).

### 2.2. Смена квеста Зубом Потрошителя (`unusualfishmod:ripper_tooth`):
- Если рыба просит слишком редкий или труднодоступный предмет, игрок может кликнуть по пруду **Зубом Потрошителя** (`unusualfishmod:ripper_tooth`).
- **Эффект:** Зуб поглощается, и текущее задание пруда мгновенно переключается на альтернативный вариант из списка доступных квестов для этой рыбы! Если альтернатив нет, пруд сообщает `no_alt`.

## 3. Менеджер прудов и Планшет Create (`society:fish_pond_manager`)

Для централизованного мониторинга всех прудов на ферме используется **Менеджер рыбных прудов (`society:fish_pond_manager`)** в паре с **Планшетом Create (`create:clipboard`)**.

```javascript
BlockEvents.rightClicked("society:fish_pond_manager", (e) => {
  const { item, hand, player, level, block } = e;
  if (hand !== "MAIN_HAND" || item !== "create:clipboard") return;
  global.addItemCooldown(player, item, 10);
  player.swing();
  const pages = global.getQuestItems(block, level);
  item.nbt = {
    Type: 1,
    PreviouslyOpenedPage: 0,
    Pages: pages,
  };
  e.cancel();
});
```

### Принцип работы:
1. Постройте сеть прудов на базе.
2. Установите блок **Fish Pond Manager**.
3. Кликните по менеджеру планшетом **Create Clipboard** в главной руке.
4. В планшет автоматически запишется полный список всех активных квестов, требуемых предметов и статусов популяции для каждого пруда в радиусе фермы!

---

## 4. Вспомогательные блоки пруда
- **Корзина рыбного пруда (`society:fish_pond_basket`)**: Собирает готовую икру и дроп рыбы без необходимости вылавливать саму рыбу.
- **Инкубатор пруда (`society:fish_pond_hatchery`)**: Ускоряет созревание и размножение мальков в пруду.

---

## 5. Резюме для игрока
1. **Заселение:** Выбирайте редкую рыбу и легендарных водных обитателей для получения ценной золотой/чёрной икры и самоцветов.
2. **Прокачка до 10 рыб:** Повышайте популяцию выполнением квестов. Используйте `unusualfishmod:ripper_tooth`, если задание требует чересчур сложный крафт.
3. **Автоматизация задач:** Держите планшет *Create Clipboard* и кликайте по *Fish Pond Manager* для моментального чеклиста всех нужных ресурсов.
