# Руководство по оптимизации характеристик покемонов (Pokemon Optimization Guide)

> **Полное техническое руководство по выведению, тюнингу характеристик (IV / EV), дружбы и природы покемонов**  
> *Содержит точные формулы расчёта `cobblemonConsumables.js`, влияние статов на производительность ферм и брейкпоинты эффективности.*

## 1. Индивидуальные значения характеристик (IVs): Конфеты IV (0..31)

В сборке *Society Sunlit Cobblemon* реализован механизм точечной модификации базовых генетических параметров (Individual Values) каждого покемона с помощью особых конфет (`cobblemon:*_candy`).

```javascript
// Логика cobblemonConsumables.js
if (effect.increase && currentStat < 31) {
  target.pokemon.ivs.set(effect.stat, currentStat + 1);
}
if (!effect.increase && currentStat > 0) {
  target.pokemon.ivs.set(effect.stat, currentStat - 1);
}
```

### Таблица Конфет IV:
| Характеристика | Повышающая конфета (+1 IV) | Понижающая конфета (-1 IV) | Максимум |
| :--- | :--- | :--- | :---: |
| **HP** (Здоровье) | `cobblemon:health_candy` | `cobblemon:sickly_candy` | **31** |
| **Attack** (Атака) | `cobblemon:mighty_candy` | `cobblemon:weak_candy` | **31** |
| **Defence** (Защита) | `cobblemon:tough_candy` | `cobblemon:brittle_candy` | **31** |
| **Sp. Attack** (Спец. Атака) | `cobblemon:smart_candy` | `cobblemon:numb_candy` | **31** |
| **Sp. Defence** (Спец. Защита) | `cobblemon:courage_candy` | `cobblemon:coward_candy` | **31** |
| **Speed** (Скорость) | `cobblemon:quick_candy` | `cobblemon:slow_candy` | **31** |

> **Зачем нужны понижающие конфеты?**
> 1. **Trick Room команды:** Снижение скорости до 0 IV для гарантированного первого хода в искажённом пространстве.
> 2. **Анти-Foul Play / Confuse:** Снижение физической Атаки до 0 IV у специальных атакующих для минимизации урона от замешательства.

## 2. Усилия тренировки (EVs): Моти усилий (0..252)

Очки усилий (Effort Values) определяют натренированность покемона в бою. Предел: 252 очка на один стат, максимум 510 очков суммарно.

### Таблица Моти:
| Предмет | Эффект |
| :--- | :--- |
| `cobblemon:health_mochi` | $+4$ EV к **HP** |
| `cobblemon:muscle_mochi` | $+4$ EV к **Attack** |
| `cobblemon:resist_mochi` | $+4$ EV к **Defence** |
| `cobblemon:genius_mochi` | $+4$ EV к **Special Attack** |
| `cobblemon:clever_mochi` | $+4$ EV к **Special Defence** |
| `cobblemon:swift_mochi` | $+4$ EV к **Speed** |
| `cobblemon:fresh_start_mochi` | **Полный сброс всех EV в 0** (позволяет пересобрать билд с нуля) |

## 3. Дружба (Friendship): Поффлеты и стихийные синергии (0..255)

Дружба напрямую определяет качество и количество лута на **Станции ранчо** (`02_RANCHING_STATION.md`) и скорость работы других станций.

### Формула расчёта бонуса Поффлета:
$$\text{Friendship Gain} = \text{Base} \times \text{TypeBonus}$$
- Если тип покемона совпадает с `positiveTypes`: бонус $\times 1.5$ (или $\times 2.0$ при тройном бонусе).
- Если покемон **не** совпадает и включён флаг `decreaseOthers`: покемон отвергает еду (`sunlit_cobblemon.pofflet.hated`)!

### Таблица Поффлетов:
| Поффлет | Базовый прирост | Предпочитаемые типы | Особый бонус |
| :--- | :---: | :--- | :--- |
| **Plain Pofflet** | $+4$ | Обычный (Normal), Летающий (Flying) | $\times 2.0$ для Normal ($+8$) |
| **Mossy Pofflet** | $+8$ | Травяной (Grass), Насекомый (Bug) | Прирост до $+12$ |
| **Frosty Pofflet** | $+8$ | Водный (Water), Ледяной (Ice), Стальной (Steel) | Отвергается остальными типами |
| **Deadly Pofflet** | $+8$ | Ядовитый (Poison), Призрачный (Ghost), Тёмный (Dark) | Отвергается остальными типами |
| **Spicy Pofflet** | $+8$ | Огненный (Fire), Боевой (Fighting), Электрический (Electric) | Отвергается остальными типами |
| **Captivating Pofflet** | $+16$ | Волшебный (Fairy), Психический (Psychic) | Прирост до **$+24$** |
| **Crystalline Pofflet** | $+8$ | Драконий (Dragon), Земляной (Ground), Каменный (Rock) | Отвергается остальными типами |
| **Mana Pofflet** | **$+14$** | **Универсальный** (все типы) | Стабильные $+14$ без ограничений |

## 4. Сводная таблица ключевых брейкпоинтов для всех станций

| Механика / Станция | Ключевой стат покемона | Брейкпоинт максимума | Эффект при достижении капа |
| :--- | :--- | :---: | :--- |
| **Садоводство: Сбор урожая** | **Speed** | $\ge 250$ | Поле $21 \times 21$ ($R=10$), полив за 5 сек |
| **Загадочная шахта** | **Attack + Speed** | $\ge 128 \text{ Spd} / 250 \text{ Atk}$ | Бурение за 2.5 сек, $x3$ дроп руды, 1% окаменелости |
| **Станция ремесла** | **Sp. Atk + Spd** | $\ge 250 \text{ SpAtk}$ | Каскадный шанс бонуса $200\%$ ($400\%$ для Shiny), пилорама 12 брёвен |
| **Станция ранчо** | **Friendship + HP** | $\mathbf{255 \text{ Friendship} + 250 \text{ HP}}$ | **10 сердец** $\rightarrow$ шанс ДНК Мью, Booster Energy, Сердце Феи |
| **Рейдовые боссы** | **IV 31 + EV 252** | $\text{Max IV/EV}$ | Победа над боссами 100 уровня (Xerneas, Yveltal, Giratina, Regigigas) |

## 5. Идеальный чеклист подготовки покемона (Best Practice)
1. **Выбор блестящей формы (Shiny):** Удваивает скорость, радиус и множители станций.
2. **IV Тюнинг:** Скормите 31 соответствующую конфету (`health_candy`, `mighty_candy` и т.д.) до показателя `Best` (31 IV).
3. **EV Прокачка:** Скормите 63 Моти в приоритетные статы (например, 252 Spd + 252 Atk).
4. **Дружба до 255:** Покормите покемона профильными Поффлетами или универсальным `mana_pofflet` до достижения максимальной привязанности 255.
5. **Назначение на станцию:** Разместите идеального покемона в соответствующий блок автоматизации!
