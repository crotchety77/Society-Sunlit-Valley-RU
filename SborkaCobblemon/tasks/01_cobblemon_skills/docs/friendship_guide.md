# ❤️ Полный гайд по Дружбе покемонов (Friendship Guide)

## 📌 Что такое Дружба в Cobblemon?
**Дружба (Friendship / Happiness)** — это числовой показатель привязанности покемона к тренеру, измеряемый по шкале **от 0 до 255 пунктов**.

В сборке *Society: Sunlit Cobblemon* дружба критически важна для:
1. **Эволюции покемонов** (Риолу $\rightarrow$ Лукарио, Иви $\rightarrow$ Сильвеон/Эспеон/Умбреон, Пичу $\rightarrow$ Пикачу и др. требуют дружбу $\ge 160$ или $\ge 220$).
2. **Силы ранчо (Ranching Station)**: определяет **Сердца дружбы (0–5 сердец)** для производства ценных ресурсов и книг навыков.
3. **Силы атак Return / Frustration**.

## 🔬 Развенчание мифа: Нужно ли сначала драться покемоном, чтобы сбросить EV?

> ❌ **Миф:** *«Чтобы скормить ягоду, покемон должен сначала набрать очки EV в битвах, иначе ягода не сработает».*  
> (Так было в древних играх Pokémon Emerald / Gen 3).
>
> ✅ **Реальность кода Cobblemon:** **Драться не нужно!**

В коде Cobblemon (`FriendshipRaisingBerryItem.class`) условие использования ягоды проверяется через логическое **«ИЛИ»**:

```java
public boolean canUseOnPokemon(Pokemon pokemon) {
    // Ягоду МОЖНО съесть, если:
    // 1) Есть EV для снижения (EV > 0)
    // ИЛИ
    // 2) Дружба ещё не достигла максимума (Friendship < 255)
    return pokemon.getEvs().get(stat) > 0 || pokemon.getFriendship() < 255;
}
```

### 💡 Вывод:
* Если у покемона **`EV = 0`** (только что пойман или вылупился из яйца), но его дружба меньше 255 пунктов — **ягода успешно съедается**!
* EV остаётся на нуле, а **дружба гарантированно увеличивается**.
* Чтобы поднять дружбу с нуля до максимума (255), достаточно просто скормить **25–35 ягод подряд за 1 минуту**.

## 🟢 3. Покеболы и предметы-усилители

* 🟢 **Дружеский бол (`cobblemon:friend_ball`)**:
  * При поимке дикого покемона сразу же устанавливает его дружбу на **ровно 150 пунктов** (стандарт Gen 8/9, байткод `CaptureEffects.friendshipSetter(150)`).
  * Это даёт сразу **2 сердца** (или **4 сердца** для Shiny) на Ранчо без единого действия!
* 🔔 **Колокольчик спокойствия (`cobblemon:soothe_bell`)**:
  * Предмет для слота удержания (`Held Item`). Увеличивает весь входящий прирост дружбы на **+50%** (в $1{,}5$ раза).
* ✨ **Люксбол (`cobblemon:luxury_ball`)**:
  * Пойманный покемон быстрее накапливает дружбу от всех действий.

## ⚔️ 4. Естественные способы прокачки

| Действие | Прирост дружбы | Примечание |
| :--- | :---: | :--- |
| **Ходьба и путешествия** | **+1** | Каждые 128 шагов (когда покемон в команде или снаружи) |
| **Победа в битве** | **+1 ... +2** | Победа над диким покемоном или NPC-тренером |
| **Повышение уровня (Level Up)** | **+3 ... +5** | От битв или от поедания Конфет опыта (`EXP Candy`) |
| **Витамины и Моти** | **+2 ... +5** | Кормление перьями/моти/витаминами характеристик |

---

## ⚠️ 5. Что снижает дружбу покемона?

1. **Потеря сознания (Faint):** Если покемон падает без сил в битве против высокоуровневых врагов, дружба снижается на **-1 ... -5**.
2. **Горькие травы и медицина (`Energy Root`, `Revival Herb`):** Восстанавливают здоровье/воскрешают, но имеют отвратительный вкус и снижают дружбу на **-5 ... -15**.

## 🏡 6. Связка: Очки дружбы $\rightarrow$ Сердца на Станции Ранчо

Формула расчета сердец дружбы в `RanchingStationBlockEntity`:
$$\text{FriendshipHearts} = \left\lfloor 5.0 \times \frac{\text{Friendship}}{255} \right\rfloor \times (\text{Shiny ? } 2 : 1)$$

| :---: | :---: | :---: |
| **0 – 50** | 🤍 **0 сердец** | 🤍 **0 сердец** |
| **51 – 101** | ❤️ **1 сердце** | ❤️❤️ **2 сердца** |
| **102 – 152** *(150 у Friend Ball)* | ❤️❤️ **2 сердца** | ❤️❤️❤️❤️ **4 сердца** |
| **153 – 203** | ❤️❤️❤️ **3 сердца** | ❤️❤️❤️❤️❤️❤️ **6 сердец** |
| **204 – 254** | ❤️❤️❤️❤️ **4 сердца** | ❤️❤️❤️❤️❤️❤️❤️❤️ **8 сердец** |
