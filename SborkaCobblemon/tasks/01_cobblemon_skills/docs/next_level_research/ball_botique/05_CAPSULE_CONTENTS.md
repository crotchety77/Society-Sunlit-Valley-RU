# 🎁 05_CAPSULE_CONTENTS — Содержимое капсул и пулы спавна

Все награды капсул определяются на стороне сервера скриптом KubeJS:  
`kubejs/server_scripts/cobblemon/cobblemonGachaPools.js`

При открытии капсулы вызывается функция `rollGacha(level, server, itemNbt, player, pos)`.

---

## 🎲 Механика смешивания пулов и отсечения

1. **Обычный игрок**:
   * **Regular (Q0)**, **Silver (Q1)**, **Gold (Q2)**: пул = `baseGachaSpawns + specialPool` *(смешанный шанс)*.
   * **Iridium (Q3)**: базовый пул **полностью отсекается** (`return specialPool`) $\rightarrow$ **100% ГАРАНТИЯ** тематического покемона.
2. **Игрок с книгой навыка «Гачамонщик» (`The Gachamonbler`)**:
   * 100% гарантия тематического пула наступает уже на **Gold (Q2)** и **Iridium (Q3)** (`quality >= 2.0`).
   * Шанс на Шайни удваивается (×2) для всех градаций качества.
3. **Игрок с книгой навыка «Красное и чёрное» (`The Red and the Black`)**:
   * Из 1 капсулы спавнятся сразу **2 покемона** с независимым шансом на Шайни!
