# 🔄 07_SHOP_ROTATION — Механика ротации, лимитов и обновления ассортимента

## 1. Алгоритм генерации ассортимента

В файле `ball_boutique.json` структура магазина разделена на постоянную часть и два случайных набора (`random_sets`):

```json
"random_sets": [
    {
        "rolled_count": 1,
        "random_style": "per_day",
        "trades": [ /* 593 сделки с дисками TM */ ]
    },
    {
        "rolled_count": 1,
        "random_style": "per_day",
        "trades": [ /* 52 сделки с капсулами Gachamon */ ]
    }
]
```

### Принцип работы ротации в моде `society_trading`:
1. **Стиль обновления**: `"per_day"`. Ролл привязан к игровому дню Minecraft (`dayIndex = level.getDayTime() / 24000L`).
2. **Количество выпадающих позиций**:
   - **Случайный сет 0**: Ровно **1 случайный ТМ** (`rolled_count: 1`) из 593 возможных.
   - **Случайный сет 1**: Ровно **1 случайная капсула** (`rolled_count: 1`) из 52 возможных.
3. **Персистентность**: Выбранные случайные предложения сохраняются в данных мира (`ShopData`). Перезапуск сервера или клиента **НЕ меняет** выпавшие товары до наступления нового игрового дня.

## 2. Вероятность появления конкретной капсулы

В `trades` случайного сета 1 находятся **52 сделки** с одинаковым весом по умолчанию ($W = 1$).

$$P(\text{Конкретная капсула}) = \frac{1}{52} \approx \mathbf{1.923\%}$$

### Вероятности по категориям в день:
* **Любая капсула Стартовиков (любого качества)**: $\frac{4}{52} = \frac{1}{13} \approx \mathbf{7.69\%}$
* **Конкретно Starter Pack Iridium**: $\frac{1}{52} \approx \mathbf{1.92\%}$
* **Любая Иридиевая капсула (любого типа)**: $\frac{13}{52} = \frac{1}{4} = \mathbf{25.0\%}$
* **Любая Золотая капсула**: $\frac{13}{52} = \mathbf{25.0\%}$
* **Любая Серебряная капсула**: $\frac{13}{52} = \mathbf{25.0\%}$
* **Любая Обычная капсула**: $\frac{13}{52} = \mathbf{25.0\%}$

## 3. Лимиты покупок (Purchase Limit)

Каждая капсульная сделка в JSON содержит параметр:
`"limit": 8`

* **Тип лимита**: Индивидуальный дневной лимит на выпавшее предложение для каждого игрока.
* **Сброс лимита**: Происходит автоматически при наступлении нового игрового дня (в 06:00 утра по времени мира).
* **Суммарный объём**: В течение одного игрового дня игрок может купить **максимум 8 штук** предложенной капсулы.
* **Постоянные покеболы**: Большинство специальных покеболов (Premier, Dusk, Quick, Nest и др.) **не имеют лимита** (`limit: null` / неограниченно). Pofflet Box имеет лимит 4 шт./день.
