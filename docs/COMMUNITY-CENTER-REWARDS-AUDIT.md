## 🎯 Предлагаемый формат жёлтых подсказок (Tooltips) для предметов-наград

Для всех этих предметов в `kubejs/client_scripts/tooltips/addTooltips.js` можно добавить подсказку в едином стиле:

* **В обычном виде (в инвентаре/JEI):**
  `🏹 §6Награда за «Узелок NAME» [Shift]` (или `§eМожно получить за выполнение Узелка «NAME»`)
* **При зажатии [Shift]:**
  `§7Узелок «NAME» находится в разделе «РАЗДЕЛ» Клуба в Книге квестов.`
