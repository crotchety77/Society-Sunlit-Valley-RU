## 4. Механика автопрокачки удочек (`fishingRodLeveling.js`)

Каждая пойманная рыба на удочках Aquaculture (Железная, Золотая, Алмазная, Нептуниевая, Лавовая) даёт шанс прокачать чары:
* **Приманка (`minecraft:lure`):** максимальный уровень **IV** (в ваниле макс. III).
* **Везучий рыбак (`minecraft:luck_of_the_sea`):** максимальный уровень **VI** (в ваниле макс. III).

### Вероятность повышения уровня чар за каждый успешный улов:
$$\text{Шанс} = \frac{1}{\text{Кап рандома}}$$

| Тип удочки | Обычная погода | В дождь (`isRaining()`) |
| :--- | :---: | :---: |
| **Железная / Лавовая** | $1 \text{ из } 40$ (**$2.5\%$**) | $1 \text{ из } 30$ (**$3.33\%$**) |
| **Золотая удочка** | $1 \text{ из } 35$ (**$2.86\%$**) | $1 \text{ из } 25$ (**$4.00\%$**) |
| **Алмазная удочка** | $1 \text{ из } 30$ (**$3.33\%$**) | $1 \text{ из } 20$ (**$5.00\%$**) |
| **Нептуниевая удочка** | $1 \text{ из } 20$ (**$5.00\%$**) | $1 \text{ из } 10$ (**$10.00\%$**) |
