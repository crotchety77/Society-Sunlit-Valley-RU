## Механика выпадения и использования Плюшевой капсулы

### 1. Предмет капсулы
* **Item ID:** `society:plushie_capsule` (модель: `whimsy_deco:item/gatcha_capsule`). `[FACT]`
* **Получение:**
  * Крафт: 4 любые плюшевые игрушки (`4x #society:plushies`) $\rightarrow$ 1 Плюшевая капсула (`addMiscRecipes.js:655`).
  * Рыбалка: 5% шанс из сундуков/сокровищ рыбалки (`fishingLoot.js:131`).
  * Фермерство: дроп при сборе урожая при изученном мастерстве животноводства (`farmingLoot.js:87`).
  * Награды квестов FTB Quests (`iv__prismatic_farming.snbt`).

### 2. Алгоритм открытия (`plushieCapsule.js`)
При нажатии ПКМ (`ItemEvents.rightClicked`):
1. **Списание предмета:** `item.count--` (если игрок не в Creative).
2. **Выбор плюшки:**
   ```javascript
   const plushies = Ingredient.of("#society:plushies").itemIds;
   const drop = plushies[Math.floor(Math.random() * plushies.length)];
   ```
3. **Количество:**
   * Базово: `1x`.
   * При открытом этапе `the_red_and_the_black`: `2x` (удвоенный дроп).
4. **Генерация NBT-данных:**
   * `type`: случайный характер от `0` до `14` (`rnd(0, 14)`).
   * `quest_id`: случайный квест от `1` до `3` (`rnd(1, 3)`).
   * `quality_food.quality`:
     * Базовые шансы: ★ (50%), ★★ (30%), ★★★ (15%), ★★★★ (5%).
     * С этапом `women_who_run_with_the_plushies`: повышенные шансы качества.
   * `affection`: `0` (или `2` при этапе `women_who_run_with_the_plushies`).

## Архитектура: почему ванильные плюшки не входят в пул

1. В сборке все оригинальные предметы модов `perfectplushies:*`, `cluttered:*_plush*`, `whimsy_deco:*_plush*` **вырезаны** через `globalRemovedItems.js`. `[FACT]`
2. Вместо них KubeJS динамически регистрирует расширенные блоки с префиксом `adv_` (`plushieReRegister.js:131`).
3. Только эти 62 `adv_`-предмета добавляются в тег `#society:plushies`. Разработческие пасхалки `perfectplushies` (`daniel_plushie`, `nyf_plushie`, `sirjain_plushie` и др.) намеренно **исключены** автором сборки из `global.originalPlushies`. `[FACT]`
