# Архитектура тултипов, редкости предметов и локализации

Данный документ фиксирует стандарты, архитектурные решения и сравнительный анализ подходов к локализации и созданию подсказок (тултипов) в сборке **Society: Sunlit Valley**.

---

## 1. Архитектура визуализации предметов (3 уровня)

Визуальный облик предметов в сборке управляется тремя взаимосвязанными системами:

```
┌─────────────────────────────────────────────────────────────┐
│ 1. Базовый уровень: KubeJS Startup Script                   │
│    kubejs/startup_scripts/registration/modifyItems.js       │
│    • item.rarity = "common" / "uncommon" / "rare" / "epic"  │
│    • Задаёт цвет названия в игре (белый/жёлтый/голубой/фиол)│
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│ 2. Оверлей тултипа: Мод Tooltip Overhaul                    │
│    config/tooltipoverhaul/custom_frames.json                │
│    • Кастомные текстурные рамки (diamond, king, amethyst)   │
│    • Градиенты фона и спецэффекты (metal_shining)           │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│ 3. Всплывающее уведомление и лучи: Мод Loot Journal         │

│    • Лучи сияния (Ray Glow), наследующие цвет редкости      │
└─────────────────────────────────────────────────────────────┘
```

## 2. Сравнение методов добавления тултипов и перевода

### Подход 1: Чистый ванильный Ресурспак (`resourcepacks/*.zip`)
* **Суть**: Перевод только стандартных языковых файлов `.json`.
* ➕ **Плюсы**: Легко распространять отдельно от сборки.
* ➖ **Минусы и ограничения**:
  * ❌ **НЕ умеет** динамические подсказки (раскрытие по `[Shift]`, скрытие строк).
  * ❌ **НЕ умеет** считывать NBT-данные (прочность, заряды, уровень, качество).
  * ❌ **НЕ умеет** переводить NBT-записки Candlelight, серверный чат, кастомные GUI.
  * ⚠️ Игрок может случайно отключить ресурспак в меню настроек.

---

### Подход 2: Прямой текст в KubeJS (`tooltip.add("...", Text.of("..."))`)
* **Суть**: Текст подсказки захардкожен прямо внутри `.js` скрипта.
* ➕ **Плюсы**:
  * ⚡ Максимально быстро пишется (всё в одном файле).
  * 🔄 Моментально перезагружается по `F3 + T`.
* ➖ **Минусы**:
  * ❌ Нет мультиязычности (текст всегда на одном языке).
  * 📜 При масштабировании JS-скрипты превращаются в «простыни» текстов.
  * ⚠️ Опечатка в синтаксисе JS может сломать работу всех клиентских скриптов.

---

### Подход 3: Гибридный стандарт (`KubeJS Logic + JSON Lang-файлы`) 🌟
*(Используется автором сборки для большинства ключевых улучшений)*

* **Суть**: Вся **логика** (проверка `[Shift]`, чтение NBT, условия) пишется в KubeJS через `Text.translatable(...)`, а сами **тексты** живут в языковых файлах `ru_ru.json` / `en_us.json`.

```javascript
// client_scripts/tooltips/addTooltips.js
ItemEvents.tooltip((tooltip) => {
  tooltip.add(
    "society:tiny_gnome",
    Text.translatable(
      "item.society.tiny_gnome.description",
      Text.translatable("block.society.loom").darkGreen()
    ).green()
  );
});
```

```json
// kubejs/assets/society/lang/ru_ru.json
{
  "item.society.tiny_gnome.description": "Используйте на %s, чтобы дать 25%% шанс производства редкой мебели",
  "block.society.loom": "Ткацкий станок"
}
```

* ➕ **Плюсы**:
  * 🌍 **Мультиязычность**: При смене языка на английский или китайский подставится соответствующий перевод.
  * 🧩 **Динамические аргументы (`%s`)**: Если целевой блок переименуется, подсказка обновится везде автоматически.
  * 🎮 **Полная поддержка `[Shift]` и NBT**: KubeJS считывает параметры предмета, а JSON красиво их форматирует.
  * 🛡️ **Безопасность**: Правка текстов в JSON никогда не сломает исполняемый код JS.
  * 📦 **100% совместимость с экспортом**: Позволяет в любой момент собрать автономный `.zip` ресурспак.

## 3. Влияние на производительность (Рендеринг и FPS)

* **Миф**: *«KubeJS тратит ресурсы на постоянный рендеринг тултипов»*.
* **Реальность**: **Разницы в производительности между чистым ресурспаком и KubeJS нет (0.00%)**.
  * `ItemEvents.tooltip` отрабатывает только в момент построения списка строк (`ItemStack.getTooltipLines()`).
  * Сама отрисовка пикселей на экране выполняется стандартным ванильным движком Minecraft.
  * Нагрузка на GPU и CPU абсолютно эквивалентна стандартному тултипу ванильного яблока.

## 4. Стратегия развития и рефакторинга кодовой базы

### 🚫 Почему НЕ нужно тотально переписывать текущие скрипты:
1. **Принцип «Работает — не трогай»**: Текущие скрипты (`longwingsTooltips.js`, `etceteraTooltips.js`, `invitationTooltips.js` и др.) уже оттестированы и стабильны. Ручная массовая переделка создаёт риск случайных регрессий и опечаток.
2. **Экономия времени**: Перенос сотен строк вручную нерационален.
3. **Автоматизация**: При необходимости выгрузки всех текстов перед релизом сборки можно запустить автоматический парсер-мигратор (Python), который сделает это за несколько секунд.

###  Правило «Эволюционного стандарта» (Forward-Only):
* **Старые рабочие скрипты**: Оставляем в их текущем рабочем виде.
* **Новые задачи и моды**: Создаём по **Гибридному стандарту** (`translations/*.json` + `Text.translatable` в KubeJS).
* **Быстрые одиночные тесты/заметки**: Допускается прямая строка `Text.of("...")` для экономии времени.

## 5. Шаблоны и примеры реализации (Cheat Sheet)

### А. Базовый тултип с трансляцией
```javascript
ItemEvents.tooltip((tooltip) => {
  tooltip.add("quark:diamond_heart", [
    Text.translatable("tooltip.society.diamond_heart.biomancy")
  ]);
});
```

### Б. Тултип с динамической подстановкой `%s`
```javascript
// Вставляет переведённое имя станка в цветной текст подсказки
tooltip.add(
  "society:tiny_gnome",
  Text.translatable(
    "item.society.tiny_gnome.description",
    Text.translatable("block.society.loom").darkGreen()
  ).green()
);
```

### В. Продвинутый тултип с `[Shift]` и NBT
```javascript
ItemEvents.tooltip((tooltip) => {
  tooltip.addAdvanced("society:custom_tool", (item, advanced, text) => {
    if (tooltip.shift) {
      text.add(1, Text.translatable("tooltip.society.custom_tool.details"));
      if (item.nbt && item.nbt.contains("level")) {
        text.add(2, Text.translatable("tooltip.society.custom_tool.level", item.nbt.getInt("level")));
      }
    } else {
      text.add(1, Text.translatable("tooltip.society.hold_shift"));
    }
  });
});
```
