### Особенности таблицы:
* **2 независимые вкладки:**
  * `TM-disks` — 63 уникальных диска (67 шт. всего).
  * `TR-disks` — 169 уникальных дисков (объединены из бочек #2 и #3 со сложением дубликатов).
* **5 структурированных колонок:**
  1. `ID предмета` — точный игровой ID (`simpletms:tm_sandattack`, `simpletms:tr_karatechop`).
  2. `Номер` — правильный номер с числовой сортировкой (`TM-1`, `TM-2`, ... `TM-103`).
  3. `Название (EN / RU)` — английское название и русский перевод из Cobblemon.
  4. `Тип атаки` — стилизованная ячейка с официальным цветом типа покемона (Водный, Огненный, Электрический и т.д.).
  5. `Количество` — суммарное количество дисков.
* **Закреплённый заголовок (Freeze Panes)**, зебра-подсветка строк и авто-подсчёт суммы `SUM()`.

## 🔍 Сбор данных в JSON (включая Тип)

Скрипт автоматически определяет стихийный тип атаки (`type`) из тегов предмета (`#simpletms:type_<type>_tr` / `#simpletms:type_<type>_tm`):

```json
{
  "id": "simpletms:tr_thief",
  "name": "TR-168: Thief",
  "type": "dark",
  "count": 1
}
```

## ⌨️ Как сканировать бочки в игре

Скрипт KubeJS: [`scripts/barrel_tm_scanner.js`](file:///c:/Users/Foxi8/OneDrive/Рабочий%20стол/СозданиеПеревода/tasks/Disk_copy_barrel/scripts/barrel_tm_scanner.js)

| Клавиша | Где нажимать | Действие |
| :--- | :--- | :--- |
| **`F8`** *(или `Shift + B`)* | Внутри открытой бочки/сундука | **Сканировать** (сохраняет ID, имя, количество и **тип атаки**) |
| **`Shift + F8`** | В любой момент игры | **Очистить базу** и начать с Бочки #1 |
