# Локализация мода: automobility (Automobility: Модульные автомобили)

## 1. Визуальный контекст и ключевые модули

### 🚗 Сборка и обслуживание:
* **Стол автомеханика** (`block.automobility.auto_mechanic_table`) — верстак для конструирования машины из 3 компонентов (Кузов + Двигатель + Колёса).
* **Монтировка** (`item.automobility.crowbar`) — клик ПКМ по автомобилю безопасно разбирает его обратно на составные части.
* **Жатка и Плуг** (`attachment.automobility.*`) — навесные модули для автоматической уборки урожая и вспашки грядок при езде по полям.
