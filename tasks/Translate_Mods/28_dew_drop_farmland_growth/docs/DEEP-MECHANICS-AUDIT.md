## 2. ИТЕРАЦИЯ 1 — Скрытые условия, геометрия и триггеры

### 💧 1. Геометрия установки спринклеров и Y-уровни
* **Что происходит в коде (`CropHandlerUtils.class:isNearSprinkler`):**
  ```java
  BlockPos minPos = farmlandPos.offset(-4, 0, -4);
  BlockPos maxPos = farmlandPos.offset(4, 1, 4);
  for (BlockPos checkPos : BlockPos.betweenClosed(minPos, maxPos)) {
      if (inRange(tierRadius, checkPos, farmlandPos) && level.getBlockState(checkPos).is(SPRINKLER_TAG)) {
          return true;
      }
  }
  ```
* **Разбор высоты (Y-Axis):**
  - Относительный диапазон: `Y = 0` (уровень самой пашни) и `Y = 1` (уровень растения / над пашней).
  - **Вариант А (Традиционный):** Спринклер стоит на земле над блоком пашни (`Y = 1`).
  - **Вариант Б (Встроенный в пашню):** Спринклер вкопан в сетку пашни вместо одного блока грязи (`Y = 0`).
  - **Результат:** Спринклер работает идеально в обоих случаях! Игрок может строить плоские поля без выступающих блоков.

### ⏰ 2. Суточный таймер полива (6:00 утра)
* Вся система влажности и высыхания привязана к **рассвету (6:00 AM)**.
* В момент 6:00 утра сначала срабатывает полив спринклеров и увлажняющих удобрений (`isNearSprinkler`, `HYDRATING_FARMLAND`), и только после этого проверяется шанс высыхания (`dailyDryChance`).
* Благодаря этому культуры на спринклерах **никогда не увядают и не засыхают**.

## 3. ИТЕРАЦИЯ 2 — Как получить максимальную выгоду? (Связки и экономика)

### 🌾 Связка 1: «Бесконечный комнатный сад»
* **Компоненты:** Садовый горшок (`dew_drop_farmland_growth:garden_pot`) + 1x Элитное увлажняющее удобрение (`deluxe_hydrating_fertilizer`).
* **Как работает:**
  1. Ставим садовый горшок в любом доме / подвале.
  2. Кликаем по нему ПКМ с `deluxe_hydrating_fertilizer`. Горшок навсегда переходит в состояние `DELUXE=true`.
  3. Сажаем редкую культуру (например, Ананас, Древний плод или Древесный побег).
* **Профит:** Горшок **никогда не сохнет**, не требует источника воды, игнорирует сезоны года и не занимает место под спринклер.

### 💰 Связка 2: «Иридиевый комбайн качества»
* **Формула шанса золота (`globalBlockEntityHandlers.js`):**
  $$\text{goldChance} = 0.2 \times \frac{\text{seedQuality} \times 4.6}{10} + 0.2 \times \text{fertilizer} \times \frac{\text{seedQuality} \times 4.6 + 2}{12} + 0.01$$
* **Шанс Иридия (Quality 3):**
  $$\text{iridiumChance} = \frac{\text{goldChance}}{2} \quad (\text{только при } \text{fertilizer} \ge 2)$$
* **Вывод для фермера:**
  - На **Pristine Quality Fertilizer (`fertilizer = 3`)** шанс золотого урожая достигает **~35-45%**, а шанс Иридия — **~18-22%** с каждого куста.
  - В сочетании с книгой *«Качество земли»* (удвоение надбавки за качество) прибыль с грядки вырастает в **3.0–4.0 раза**.

## 4. ИТЕРАЦИЯ 3 — Что удивит опытного игрока? (Контринтуитивные свойства)

### ⚠️ 1. Обильное удобрение (`bountiful_fertilizer`) — ловушка для дорогих культур!
* **Код:** `if (block.is(BOUNTIFUL)) return -1;` $\rightarrow$ `if (fertilizer == -1) return 0;`
* **Эффект:** Даёт 25% шанс получить +1 плод, но **полностью отключает качество урожая** (урожай всегда обычный, множитель цены $1.0\times$).
* **Вывод:** Обильное удобрение выгодно ТОЛЬКО для дешёвых массовых культур под переработку в сок/джемы (где качество сырья не имеет значения). На дорогих ягодах и культурах для прямой продажи оно **приносит убыток** по сравнению с качественными удобрениями.

### 🌿 2. Округление `floor(maxAge / 2)` у Увлажняющего удобрения
* Для культур с 4 стадиями роста (например, свекла, `maxAge = 3`): $\lfloor 3 / 2 \rfloor = 1$.
  - Автополив работает только на стадии 0 (всего 1 день!).
* Для культур с 8 стадиями (пшеница, `maxAge = 7`): $\lfloor 7 / 2 \rfloor = 3$.
  - Автополив работает на стадиях 0, 1, 2, 3 (4 полных дня!).
* **Вывод:** Эффективность увлажняющего удобрения в 4 раза выше на медленнорастущих многостадийных культурах.
