## 2. Глубокий разбор механик

### 💧 А. Механика Увлажняющего удобрения (`hydrating_fertilizer`)
* **Первичный факт в коде (`CustomFarmland.class:280-312`):**
  ```java
  if (farmland.is(HYDRATING_FARMLAND)) {
      if (cropBlock instanceof CropBlock) {
          int age = cropBlock.getAge(cropState);
          int maxAge = cropBlock.getMaxAge();
          if (age < Math.floor(maxAge / 2.0)) {
              isHydrated = true;
          }
      }
  }
  ```
* **Суть механики для игрока:**
  - Удобрение удерживает влагу в грядке **автоматически**, но только пока культура не достигнет **половины своего созревания** (`age < floor(maxAge / 2)`).
  - *Пример:* Пшеница имеет 7 стадий роста (`maxAge = 7`). Половина с округлением вниз = `3`. На стадиях 0, 1, 2, 3 грядка поливает себя сама каждое утро в 6:00. Начиная со стадии 4 грядка высохнет, и игроку потребуется полить её лейкой или использовать спринклер.
  - **Для чего создано:** Дешёвый стартовый вариант для экономии времени полива на ранних этапах игры.

---

### 🌟 Б. Механика Элитного увлажняющего удобрения (`deluxe_hydrating_fertilizer`)
* **Первичный факт в коде (`CustomFarmland.class:314-328`):**
  ```java
  if (farmland.is(DELUXE_HYDRATING_FARMLAND)) {
      isHydrated = true;
  }
  ```
* **Суть механики:**
  - Грядка с этим удобрением **никогда не высыхает**. Полив не требуется вообще на протяжении всего цикла жизни любых культур.
  - Идеально подходит для удалённых ферм и Садовых горшков (`garden_pot`), которые не могут быть политы спринклерами.

### ⏩ В. Скоростные удобрения (`weak`, `strong`, `hyper`)
* **Первичный факт в коде (`CropHandlerUtils.class:getFertilizerIncrease`):**
  ```java
  int step = 1;
  if (farmland.is(WEAK_FERTILIZED_FARMLAND)) step = 2;
  if (farmland.is(STRONG_FERTILIZED_FARMLAND)) step = 3;
  if (farmland.is(HYPER_FERTILIZED_FARMLAND)) step = 4;
  return Math.min(step, maxAge);
  ```
* **Суть механики:**
  - Стандартная пашня продвигает рост культуры на +1 стадию в день (в 6:00 утра при условии влажности).
  - **Слабое (+1 день):** перескакивает сразу на +2 стадии за утро (созревает в 2 раза быстрее).
  - **Сильное (+2 дня):** перескакивает на +3 стадии за утро.
  - **Гипер (+3 дня):** перескакивает на +4 стадии за утро.

---

### 💦 Г. Спринклеры (`SprinklerBlock.class` и `CropHandlerUtils.class:isNearSprinkler`)
* **Радиусы полива:**
  - `iron_sprinkler`: радиус $r = 1 \rightarrow 3 \times 3$ (8 грядок вокруг спринклера).
  - `gold_sprinkler`: радиус $r = 2 \rightarrow 5 \times 5$ (24 грядки).
  - `diamond_sprinkler`: радиус $r = 3 \rightarrow 7 \times 7$ (48 грядок).
  - `netherite_sprinkler`: радиус $r = 4 \rightarrow 9 \times 9$ (80 грядок).
* **Особенности:**
  - Работают по суточному циклу: поливают пашню в **6:00 утра** непосредственно перед утренним тиком высыхания.
  - Могут быть встроены вровень с пашней.
  - Поддерживают украшение: `ПКМ` обычной палкой по спринклеру устанавливает свойство `STICKLOGGED = true` (визуальный декоративный шест).
