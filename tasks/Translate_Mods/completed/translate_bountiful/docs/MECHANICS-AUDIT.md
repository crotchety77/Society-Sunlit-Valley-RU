## 2. Механика репутации доски (Board Reputation)

У каждой Доски объявлений есть независимый показатель **Репутации (Reputation)**, накапливаемый при успешной сдаче выполненных контрактов.

### Таблица тиров репутации и редкости контрактов

| Ранг редкости | Порог репутации (Rep Tier) | Базовый вес (Weight) | Цвет в GUI | Особенности заданий |
| :--- | :---: | :---: | :---: | :--- |
| **Обычный (Common)** | **-30** | **1024** | ⚪ Белый | Простые базовые предметы (пшеница, морковь, треска, доски) |
| **Необычный (Uncommon)** | **+5** | **512** | 🔵 Бирюзовый | Урожай повышенной ценности, блюда, переработанные материалы |
| **Редкий (Rare)** | **+15** | **256** | 🟡 Жёлтый | Редкая рыба, критерии (ловля в открытой воде), минералы |
| **Эпический (Epic)** | **+25** | **128** | 🟣 Пурпурный | Драгоценные камни, сложные кулинарные рецепты, крупные партии |
| **Легендарный (Legendary)** | **+30+** | **6** | 🟠 Золотой | Самые ценные контракты с максимальной выплатой в монетах |

## 3. Математическая модель генерации контрактов

### 1. Формула шанса появления редких заказов
Вес вероятности выбора пула задач корректируется репутацией доски по формуле:

```
Вес = BaseWeight × WeightMult × (2.25 ^ -max(0, TargetRarityTier - CurrentBoardRepTier))
```

* **Первичный факт в коде (`BountyRarity.java`):**
  ```java
  private final double weightAdjustedFor(BountyRarity target) {
      return (double) this.weight / Math.pow(2.25, Math.max(0, target.ordinal() - this.ordinal()));
  }
  ```
* **Вывод:** Каждое повышение ранга репутации доски увеличивает шанс выпадения заказов следующей редкости более чем в **2.25 раза**.

---

### 2. Механика скидки на требования (Discount)
В шапке интерфейса доски отображается показатель **Discount: X.X%**.

* **Что делает скидка:** Снижает необходимое количество требуемых предметов для сдачи контракта без уменьшения итоговой награды монетами.
* **В коде:** Рассчитывается динамически через метод `BountyCreator.Companion.getDiscount(rep)`.

### 2. Динамическая смена сезонов на Доске объявлений (`updateBountyBoard.js`):
В сборке реализован серверный скрипт KubeJS:
* При правом клике по Доске объявлений скрипт проверяет текущий сезон мира через `global.getSeasonFromLevel(level)`.
* Если на доске установлен сезонный указ, его ID автоматически перезаписывается на активный сезон года (например, `summer` $\rightarrow$ `autumn`), обновляя ассортимент доступных сезонных контрактов.

---

### 3. Экономика наград (Numismatics):
Все награды в сборке выплачиваются через пул `coin_rews.json`:
* **Обычные заказы:** 2–4 монеты Шестерёнки (`numismatics:cog` = 64●).
* **Необычные / Редкие заказы:** Спрокеты (`numismatics:sprocket` = 16●) и Кроны (`numismatics:crown` = 256●).
* **Эпические заказы:** Золотые солнца (`numismatics:sun` = 4096●).

## 5. Механика непредметных целей (Критерии / Actions)

В Bountiful поддерживаются задания на выполнение действий (`"type": "criteria"`).

### Особенности реализации и исправления:
1. **Отслеживание прогресса:**
   Критерий проверяет системный триггер достижений (например, `farmersdelight:use_cutting_board` или `minecraft:fishing_rod_hooked`) и объект `conditions`.
2. **Локализация:**
   Текст задания считывается через ключ `bountiful.entry.<id>` из языкового файла `ru_ru.json`.
3. **Иконки:**
   Поскольку у критериев нет физического предмета в `content`, поле `"icon": "<item_id>"` обязательно задаётся вручную, предотвращая отображение черно-фиолетового квадрата ошибки.

## 6. Формулировки всплывающих подсказок (KubeJS Tooltips)

В сборке активен скрипт [bountifulTooltips.js](file:///c:/Users/Foxi8/OneDrive/Рабочий%20стол/СозданиеПеревода/kubejs_scripts/client/bountifulTooltips.js):

* **Доска объявлений (`bountiful:bountyboard`):**
  > *Центральный терминал контрактов и заданий.*  
  > `ПКМ:` открыть список доступных заказов.  
  > `Указы (Decrees):` задают тематику появляющихся заданий (фермерство, геология, рыбалка...).  
  > `Сдача заказа:` возьмите выполненный свиток в руку и нажмите ПКМ по доске.  
  > `§e● Награды выплачиваются монетами Numismatics.`

* **Распоряжение (`bountiful:decree`):**
  > *Определяет специализацию заказов на Доске объявлений.*  
  > `Установка:` поместите указ в соответствующий слот внутри доски объявлений.  
  > `Сезонные указы:` автоматически переключаются под текущий сезон года.
