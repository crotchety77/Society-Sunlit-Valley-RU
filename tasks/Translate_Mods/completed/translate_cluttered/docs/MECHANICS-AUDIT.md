## 1. Реверс-инжиниринг механик (Код и Java-классы)

### 🔧 Ручная дрель (`HandDrillItem.class`)
- **Логика работы:** Класс содержит внутренний `BLOCK_CYCLE_MAP`.
- **Обычный клик (ПКМ):** Переключает визуальную вариацию блока на следующую по циклу (детали полок, наполнение шкафчиков, тип посуды).
- **Клик в приседе (Shift + ПКМ):** Вызывает метод горизонтального вращения блока вокруг своей оси без разрушения и выпадения дропа.

### 🍄 Прыгучий гриб (`BouncyMushroomBlock.class`)
- **Поглощение урона:** Метод `fallOn` полностью обнуляет урон от падения (`damage = 0.0f`), если игрок не приседает.
- **Подбрасывание:** Метод `bounceUp` инвертирует вектор вертикальной скорости (`Vec3.y * -1.0d` для живых существ и `-0.8d` для предметов/мобов).

### 📦 Контейнеры и хранилища (`CustomHorizontalWoodBlock`)
- Тумбочки, холодильники, картонные коробки и шкафчики открывают стандартный GUI инвентаря на 9–27 слотов.
