## 2. Скрытые механики и свойства в коде

1. **💧 Заправка водой:**
   * Клик ПКМ по любому источнику воды, котлу или дождю мгновенно восполняет весь запас воды лейки.
2. **🌱 Бонус костной муки (25% шанс):**
   * При каждом поливе грядки с культурой код с вероятностью `25%` (`Config.bonemealOdds = 25`) накладывает эффект мгновенного роста костной муки!
3. **🧱 Превращение земли в грязь (25% шанс):**
   * При поливе обычной сухой земли есть `25%` шанс (`Config.mudOdds = 25`) превратить её в блок грязи (`minecraft:mud`).
4. **🔥 Тушение огня:**
   * Лейка мгновенно гасит огонь и горящие костры в области полива.
5. **🌋 Незер (Ад):**
   * Обычные лейки (медная, железная, золотая, алмазная) **не работают в измерении Незера** (вода испаряется).
   * **Иридиевая (Незеритовая) лейка** благодаря зачарованию незеритом работает даже в Незере (`Config.allowNetheriteCanAnyways = true`).

## 3. Крафты и улучшение
Все лейки последовательно улучшаются на **Кузнечном столе** (`Smithing Table`) с помощью шаблонов кузнечного улучшения Society:
* Медная + Железный слиток + Железный шаблон $\rightarrow$ **Железная лейка**
* Железная + Золотой слиток + Золотой шаблон $\rightarrow$ **Золотая лейка**
* Золотая + Алмаз + Алмазный шаблон $\rightarrow$ **Алмазная лейка**
* Алмазная + Незеритовый/Иридиевый слиток + Незеритовый шаблон $\rightarrow$ **Иридиевая лейка**
