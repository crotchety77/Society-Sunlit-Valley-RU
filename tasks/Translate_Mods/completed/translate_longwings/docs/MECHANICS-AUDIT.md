## 2. Подробный технический разбор механик

### 1. 🧬 Механика пассивного дропа и скрещивания (`modifyLongwings.js`)
* **Таймер:** Каждые **6000 тиков (5 минут)** сущность производит расчёт.
* **Дроп:**
  * Бабочки производят **Янтарь бабочки** (`society:butterfly_amber`).
  * Мотыльки производят **Пыльцу мотылька** (`society:moth_pollen`).
* **Формула вероятности:**
  $$\text{Шанс} = \min(1.0,\; \text{УникальныеЦветы} \times 0.15 - \text{Соседи} \times 0.10)$$
  * **Радиус сканирования цветов:** 4 блока ($9 \times 9 \times 9$). Учитываются только **уникальные** виды цветов.
  * **Штраф за скученность (Дебафф соседей):** Каждый сосед в радиусе 8 блоков снижает шанс на **10%**. Если соседей слишком много, шанс становится 0%.
  * **Поедание цветка:** С шансом 8% при дропе особь съедает 1 цветок.
* **Скрещивание:**
  * При наличии партнера в радиусе 8 блоков шанс спаривания равен $\text{Шанс} / 4$.
  * Откладываются **Яйца гусениц** (`society:caterpillar_eggs`) с вычисленным генетическим видом и размером.
  * С шансом **0.1% (1/1000)** вместо яиц выпадает реликвия **`society:the_metamorphosize`** (Книга навыков «Метаморфозы»).

### 2. 📦 Инкубатор для гусениц (`society:caterpillar_box`)
* Принимает яйца гусениц через инвентарь или воронки.
* Каждые **5 минут (6000 тиков)** потребляет 1 яйцо и спавнит взрослую особь с сохранением выведенного вида и размера.

### 3. 🕸 Ловчий сачок (`CatchingNetItem.java`)
* Дистанция: 1.5 блока перед игроком.
* Расход прочности: только с вероятностью 1/15 ≈ 6.67% (`random.nextInt(15) < 1`). Реальный ресурс — **960 взмахов**.

### 4. 📖 Справочник-климатомер (`EventsForge.playerTickEvent`)
* При удержании книги в любой руке выводит температуру и влажность биома на Actionbar над хотбаром в реальном времени.

### 5. 🧪 Ритуал эффектов стаи (`BowlPlacedItem.java`)
* Питьё Миски с сахарной водой возле:
  * **≥ 10 бабочек:** эффект «Грация бабочек» (планирующий полёт, 100% защита от падения).
  * **≥ 10 мотыльков:** эффект «Чутьё на семена» (8% шанс дропа древних семян Факельника/Кувшинника при срезе листвы).

## 3. Таблица ключевых вероятностей

| Механика | Условие в коде | Итоговая вероятность |
| :--- | :--- | :--- |
| **Бафф цветка** | `scannedFlowers.push(id)` | **+15%** за каждый уникальный вид цветка |
| **Штраф за соседа** | `entities.length * 0.1` | **-10%** за каждую особь в радиусе 8 блоков |
| **Скрещивание** | `Math.random() <= (chance / 4)` | До **25%** каждые 5 минут |
| **Выпадение книги «Метаморфозы»** | `Math.random() <= 0.001` | **0.1% (1 из 1000)** при спаривании |
| **Поедание цветка** | `Math.random() <= 0.08` | **8.0%** при успешном дропе |
| **Износ сачка** | `random.nextInt(15) < 1` | **6.67% (1/15)** при взмахе |
| **Дроп семян Сниффера** | `random.nextInt(25) < 2` | **8.0%** на блок листвы |
