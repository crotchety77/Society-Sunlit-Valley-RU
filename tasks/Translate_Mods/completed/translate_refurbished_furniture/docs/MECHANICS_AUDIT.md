# 🛠️ Технический аудит интерактивных механик: Refurbished Furniture

**Мод:** `MrCrayfish's Refurbished Furniture Mod` (`refurbished_furniture-forge-1.20.1-1.0.20.jar`)  
**Назначение:** Полный реестр интерактивных возможностей блоков, неочевидных фич и скрытых механик для базы знаний и проектирования внутриигровых подсказок (tooltips).

## 🔬 Глубокий разбор ключевых механик

### 1. 🎨 Коврик для двери (`DoorMatBlockEntity`):
* Размер холста: **14×10 пикселей**.
* Поддерживает полную палитру из 16 ванильных красителей Minecraft.
* Игрок может нарисовать индивидуальный логотип, приветствие или предупреждающий знак.

### 2. ♻️ Мусорное ведро (`RecycleBinBlockEntity`):
* Требует подключения к электрогенератору.
* Имеет 3 входных слота.
* За каждый утилизированный предмет начисляет очки опыта (`experiencePerItem`).
* Кнопка **«Забрать опыт»** в GUI мгновенно передаёт накопленные уровни/сферы опыта игроку.

### 3. ⚡ Электросеть и «Умный дом»:
* Генератор вырабатывает энергию из любого горючего (уголь, доски, лава).
* С помощью **Гаечного ключа** игрок нажимает на узел генератора, а затем на узел прибора (плита, тостер, микроволновка, морозильник, вентилятор, компьютер).
* Если приборов слишком много — сеть перегружается (`Overloaded`).
* В приложении **«Умный дом» (HomeControl)** на компьютере можно одной кнопкой гасить весь свет в доме или отключать выбранные приборы.

### 4. 🍳 Кулинарный конвейер:
1. **Подготовка:** Нарезка пшеницы/сыра/хлеба на **Разделочной доске** ножом.
2. **Термообработка:**
   * Сковорода на плите $\rightarrow$ жарка котлет и яичниц с переворачиванием лопаткой.
   * Духовка плиты $\rightarrow$ выпекание сборных пицц и пирогов.
   * Тостер $\rightarrow$ быстрое приготовление тостов под ягодные джемы.
3. **Сервировка:** Выкладка порций на **Тарелку** для праздничного обеда.
