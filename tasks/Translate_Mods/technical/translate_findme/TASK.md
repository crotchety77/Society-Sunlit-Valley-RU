# Задача: Локализация мода findme

**Namespace:** `findme`
**JAR-файл(ы):** `findme-3.2.3-forge.jar`

### Статистика строк:
* Всего строк: **4**
* Предметов (`item.`): **0** | Блоков (`block.`): **0**
* GUI / Меню: **0** | Тултипов: **0**
* Не переведено: **3** | Переведено: **1**

### Порядок работы:
1. Согласовать перевод в файле `new_translate.md` согласно глоссарию `glossary.md` и правилам форматирования.
2. Запустить скрипт `python tasks/Translate_Mods/translate_findme/scripts/apply_and_sync.py`.
3. Проверить физический файл игры и нажать `F3 + T` в Minecraft.
