# Локализация мода: findme

**JAR:** `findme-3.2.3-forge.jar` | **Всего строк:** 4 | **Не переведено:** 3

## 1. Визуальный контекст и оформление
* Форматирование: Названия предметов/блоков начинаются с Заглавной буквы.
* Валюта: использовать значок монеты `§e●` (`U+25CF`).
* Тултипы: подсветка клавиш `§6Shift + ПКМ§7`.

## 2. Непереведённые строки (требуют перевода)

```json
{
  "key.findme.pull_one": "TODO: Pull 1 Item From Nearby Inventories",
  "key.findme.pull_stack": "TODO: Pull 1 Stack From Nearby Inventories",
  "key.findme.category": "TODO: Find Me"
}
```

## 3. Существующие переводы (для контекста)

```json
{
  "key.findme.search": "Поиск предметов в ближайших инвентарях."
}
```
