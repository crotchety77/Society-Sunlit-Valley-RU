# Задача: Локализация мода pandalib

**Namespace:** `pandalib`
**JAR-файл(ы):** `pandalib-forge-mc1.20-0.5.2-SNAPSHOT.jar`

### Статистика строк:
* Всего строк: **1**
* Предметов (`item.`): **0** | Блоков (`block.`): **0**
* GUI / Меню: **0** | Тултипов: **0**
* Не переведено: **1** | Переведено: **0**

### Порядок работы:
1. Согласовать перевод в файле `new_translate.md` согласно глоссарию `glossary.md` и правилам форматирования.
2. Запустить скрипт `python tasks/Translate_Mods/translate_pandalib/scripts/apply_and_sync.py`.
3. Проверить физический файл игры и нажать `F3 + T` в Minecraft.
