## 🎯 Краткие выводы аудита (TL;DR)

1. **Точный список станков, сохраняющих качество сырья (`hasQuality = true`):**
   * 🧀 **Сырный пресс** (`society:cheese_press`): Качество молока (1★–3★) $\rightarrow$ Качество сыра (1★–3★).
   * 🥚 **Майонезный автомат** (`society:mayonnaise_machine`): Качество яиц (1★–3★) $\rightarrow$ Качество майонеза (1★–3★).
   * 🐟 **Коптильня рыбы** (`society:fish_smoker`): Качество рыбы (1★–3★) $\rightarrow$ Качество копчёной рыбы (1★–3★).
   * 🌾 **Аппарат для создания семян** (`society:seed_maker`): Качество 3 плодов (1★–3★) $\rightarrow$ Качество семян (1★–3★).
   * 🍄 **Грибное бревно** (`society:mushroom_log`): Самостоятельно генерирует качество (1★–3★) на основе плотности леса вокруг (>20, >40, >60 бревен в радиусе 8).
   * 🧺 **Авто-сборщик** (`society:auto_grabber`) и 🐸 **Хижина лягушек** (`society:ribbit_hut`): Сохраняют NBT качества при заборе предметов.

2. 🔴 **КРИТИЧЕСКИЙ ФАКТЧЕК — Банка консервации (`society:preserves_jar`):**
   * **Банка консервации НЕ сохраняет качество!** В исходном коде `preservesJar.js` зарегистрирована с `initialData({ stage: 0, recipe: "" })` без поля `quality`.
   * Любые плоды (золотые, иридиевые) на выходе дают **обычное варенье / джем без качества (0★)**.
   * 👉 **Вывод:** Закладывать качественные плоды в банку консервации — **прямой убыток**! В банку нужно закладывать только сырье с **Изобильного удобрения**.

3. **Все остальные станки переработки НЕ сохраняют качество (сбрасывают в 0★):**
   * 🍷 Винодельческая бочка (`wine_keg`) — вино/сок всегда 0★.
   * 🍇 Сушилка (`dehydrator`) — сухофрукты/изюм всегда 0★.
   * 🛢️ Маслобойка (`oil_maker`) — масло/трюфельное масло всегда 0★.
   * 🧵 Ткацкий станок (`loom`) — ткань/шерсть всегда 0★.
   * ☕ Кофемашина (`espresso_machine`) — эспрессо всегда 0★.
   * 🧀 Форма для сыра Meadow (`meadow:cheese_form`) — не поддерживает Quality Food.
   * 🍲 Кулинарные котлы (`farmersdelight:cooking_pot`) — блюда всегда 0★.
   * ⚙️ Жернов Create (`create:millstone`) — мука/сахар всегда 0★.

```javascript
let hasQuality = nbt.data.quality !== undefined || [
  'society:cheese_press', 
  'society:mayonnaise_machine', 
  'society:fish_smoker', 
  'society:seed_maker'
].includes(block.id);
```

### Б. Считывание качества при загрузке сырья (строки 277–291):
```javascript
if (hasQuality && itemNbt && itemNbt.quality_food) {
  itemQuality = String(itemNbt.quality_food.quality);
} else if (hasQuality) {
  itemQuality = "0";
}
if (multipleInputs) {
  if (itemQuality) setQuality(nbt, stage, itemQuality);
} else if (itemQuality) {
  nbt.merge({ data: { quality: Number(itemQuality) } });
}
```

### В. Выдача готового продукта с качеством (строки 190–195):
