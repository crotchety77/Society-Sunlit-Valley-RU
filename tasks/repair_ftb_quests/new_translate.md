# Согласование восстановления структуры FTB Quests

## 1. «Разведение бабочек!» (`263CCA4D2EAF2629` в `iii__advanced_farming.snbt`)

### Визуальный макет в игре (1 страница, 3 абзаца):
```text
Когда две разные бабочки или мотылька находятся рядом, они могут отложить &6Яйцо гусеницы&r!

Яйца появляются естественным образом — так же, как бабочки сбрасывают янтарь и пыльцу, опыляя цветы вокруг.
&7Совет: сажайте пары бабочек среди 7–8 видов цветов (радиус 4 блока) для максимального шанса кладки (до 25%%).&r

Вид и размер яйца определяются типом родителей: скрещивание двух разных видов даёт новый, более редкий вид, а размер потомка растёт относительно среднего размера родителей.
```

## 2. «Вручение подарков» (`3E08F21BA8F69499` в `getting_started.snbt`)

### Визуальный макет в игре (1 страница, 3 абзаца):
```text
У жителей есть система дружбы, позволяющая дарить им подарки для повышения уровня отношений.

Нажмите &6Shift + ПКМ&r по жителю с предметом в руке, чтобы вручить подарок (кулдаун — &61 раз в 4 дня&r). Ежедневный разговор приносит &a+5 очков&r.

Предметы, имеющие цену продажи, всегда можно дарить. Полный список предпочтений ищите по тегу &6#villager_gift&r в JEI/EMI.
&dУниверсальные любимые подарки:&r Призматический осколок, Кроличья лапка, Чай Улун, Солнечная жемчужина, Желейное вино.
```

```text
Житель-&6торговец&r продаёт улучшения для машин в обмен на различные фермерские товары (ему также можно позвонить по телефону после посещения Пещеры Черепа). Эти улучшения добавляют машинам особые эффекты при установке.
```

## 4. «Для владельцев серверов» (`18490F31FFAB134E` в `welcome.snbt`)

### Визуальный макет в игре (1 страница, 3 абзаца):
```text
Если вы держите сервер для нескольких человек, которые заходят в разное время, вам стоит изменить длительность сезонов в файлах конфигурации.

Это можно сделать, изменив параметр &6sub_season_duration&r в файле &6config/sereneseasons/seasons.toml&r.

На больших серверах рекомендуется установить это значение на 16-20, чтобы никто не смог «прожить» целый сезон за один день.
&oПримечание: игрокам также потребуется обновить свои файлы конфигурации, чтобы интерфейс сезонов соответствовал серверному.&r
```
