# Технический аудит механики: Золотые часы (Golden Clock) и Пыльца фей (Fairy Dust)

## 1. Золотые часы (`society:golden_clock`)

### Первичные факты из кода (`goldenClock.js`):
* **ID блока:** `society:golden_clock`
* **Радиус действия:** `radius = 2` $\rightarrow$ кубическая область **5x5x5** блоков вокруг часов.
* **Время срабатывания:** `goldenClockProgTime = 1000` тиков (соответствует **7:00 AM** игрового времени, через 1000 тиков после стандартного рассвета в 6:00 AM).
* **Логика работы:**
  1. Каждый игровой день ровно в 7:00 AM сканирует все блоки в зоне 5x5x5.
  2. Для всех блоков с тегом `#society:golden_clock_advanced` вызывает функцию `global.handleProgress(level, scanBlock)`.
  3. Проигрывает звук звона напольных часов (`tanukidecor:block.grandfather_clock.chime`).

### Реальный геймплейный эффект:
* Стандартный суточный шаг всех ремесленных станков происходит на рассвете в 6:00 AM (`dayTime % 24000 == 0`).
* В 7:00 AM Золотые часы дают **ещё один дополнительный суточный шаг** (+1 день прогресса).
* **Итог:** Все станки в радиусе 5x5x5 получают **2 дня прогресса за 1 реальные игровые сутки** (удвоение скорости производства / сокращение времени на 50%).

### Примеры ускорения:
| Станок | Базовое время | С Золотыми часами (5x5x5) |
| :--- | :--- | :--- |
| **Ремесленный пресс для сыра** (`society:cheese_press`) | 2 дня | **1 день** |
| **Банка для консервации** (`society:preserves_jar`) | 3 дня | **1.5 дня** (2 сут.) |
| **Кристалляриум** (`society:crystalarium`) | 5 дней | **2.5 дня** (3 сут.) |
| **Винный бочонок** (`society:wine_keg`) | 6 дней | **3 дня** |
| **Бочка выдержки** (`society:aging_cask`) | 10 дней | **5 дней** |
| **Бочка выдержки + Сломанные часы** (`society:broken_clock`) | 5 дней | **2.5 дня** |
| **Древняя бочка** (`society:ancient_cask`) | 20 дней | **10 дней** |

## 2. Пыльца фей (`society:fairy_dust`)

### Первичные факты из кода (`fairyDust.js`):
* **ID предмета:** `society:fairy_dust`
* **Действие:** Нажатие `ПКМ` основным предметом по любому работающему станку из списка 19 ремесленных машин (`working == true && mature == false`).
* **Расход:** Тратится **1 шт.** пыльцы (в креативе не тратится).
* **Логика работы:**
  1. Вызывает `global.handleProgress(level, block)`.
  2. Мгновенно продвигает станок на **+1 стадию / +1 полный день прогресса**.
  3. Спавнит частицы свечения (`snowyspirit:glow_light`) и звук огонька (`legendarycreatures:wisp_idle`).

### Реальный геймплейный эффект:
* **Однодневные станки** (Майонез, Ткацкий станок, Экстрактор семян, Дегидратор, Маслопресс, Утилизатор): **1 пыльца = мгновенная готовность продукции!**
* **Многодневные станки** (Пресс для сыра, Бочки выдержки, Кристалляриум, Винный бочонок): **каждое нажатие мгновенно снимает 1 день ожидания**.
  - *Пример:* Чтобы мгновенно получить сыр из сырого молока в прессе (требует 2 дня), нужно применить **2 шт.** пыльцы фей подряд.
