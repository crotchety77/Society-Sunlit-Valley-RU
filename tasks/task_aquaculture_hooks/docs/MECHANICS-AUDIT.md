## 2. Скрытые механики KubeJS и сборки Society

1. **Совместимость с удочками:**
   * Крючки устанавливаются в **Ящике для снастей** (`Tackle Box`) на улучшаемые удочки (Железную, Золотую, Алмазную, Нептуниевую).
2. **Награда за «Аквариум» (Fish Tank Bundle):**
   * За полное закрытие раздела «Аквариум» в Клубе игрок получает легендарный `nether_star_hook` (в сборке называется «Нептуниевый крючок / Крючок звезды Незера»), дающий шанс вылова реликтовых тайников (`Relic Troves`).
