## 2. ИТЕРАЦИЯ 1 — Скрытые условия, триггеры и интерфейсы

### А. Интерфейсы автоматизации (Hoppers)
1. **`meadow:cheese_form` (Авто-пресс):**
   - Реализует `WorldlyContainer` на 3 слота.
   - `Direction.UP` (Сверху): принимает ведро молока и Сычужный фермент (`meadow:rennet`).
   - `Direction.DOWN` (Снизу): отдаёт готовый сырный блок и пустое ведро.
2. **`society:cheese_press` (Ремесленный пресс):**
   - Не имеет Vanilla-контейнера. Обычные воронки к нему **не подключаются**.
   - Автоматизируется **только кастомной Ремесленной воронкой** (`society:artisan_hopper`), которая считывает рецепты напрямую из реестра KubeJS (`artisanHopper.js:154`).

### Б. Катализаторы ускорения
* **Пыльца фей (`society:fairy_dust`):** Клик ПКМ по работающему `society:cheese_press` мгновенно переводит стадию в готовую (`global.handleProgress` $\rightarrow$ `global.handleBETick`), расходуя 1 пыльцу.
* **Золотые часы (`society:golden_clock`):** При активации продвигают прогресс сырного пресса сразу на 2 стадии (`goldenClock.js:14`).

## 4. ИТЕРАЦИЯ 3 — Контринтуитивность и скрытые ловушки

1. **Парадокс скорости станков:**
   * Автоматический пресс поздней игры (`meadow:cheese_form`) в **4.5 раза медленнее** базового ручного пресса (90 сек против 20 сек) и требует дополнительный ресурс (сычуг). Это балансирует возможность полной AFK-автоматизации.
2. **Ловушка элитного молока:**
   * Загрузка золотого/алмазного молока в `meadow:cheese_form` уничтожает качество, нанося игроку прямой убыток до 50–66% от потенциальной стоимости сыра.
## 5. ИТОГОВАЯ РАЗГАДКА: Механика утреннего тика (6:00 AM) и реальное время

### 🔍 Как работает счётчик дней в `society:cheese_press`?
В коде серверного обработчика станков ([`globalBlockEntityHandlers.js:593-602`](file:///c:/Users/Foxi8/OneDrive/Рабочий%20стол/СозданиеПеревода/game_data/startup_scripts/globalBlockEntityHandlers.js#L593-L602)):
```javascript
let dayTime = level.dayTime();
let morningModulo = dayTime % 24000;

if (
  forced ||
  (morningModulo >= artMachineProgTime &&
    morningModulo < artMachineProgTime + artMachineTickRate)
) {
  // Происходит переход на следующую стадию (+1 stage)
  increaseDataStage(block);
}
```

* `dayTime % 24000` — игровое время суток в Minecraft (тик 0 соответствует **6:00 AM** — наступлению утра).
* Условие `morningModulo >= 20 && morningModulo < 220` срабатывает **строго один раз в сутки — каждое утро в 6:00 AM**.
* Для завершения цикла пресса требуется пройти `stageCount = 2`.
* ⏱️ **Фактическое время созревания:** **ровно 2 игровых дня (2 перехода через 6:00 AM)**.
  - День 1 (6:00 AM): Переход на Стадию 1 (`⬛⬜`).
  - День 2 (6:00 AM): Переход на Стадию 2 (`⬛⬛`) $\rightarrow$ сыр готов к сбору (`mature = true`).
