# Полный технический аудит: Механика производства сыров и прессы для сыра

> **Контекст исследования:** Разбор двух механизмов для сыроделия (`society:cheese_press` и `meadow:cheese_form`), сравнение их механик, скорости, качества продукции, роли сычужного фермента (`Rennet`) и решение проблемы одинаковых названий.

---

## 2. Глубокий аудит механик по коду

### А. Ремесленный пресс (`society:cheese_press`)
1. **Качество ингредиентов:** В файле `globalBlockEntityHandlers.js` (строка 244) зарегистрирован флаг `hasQuality`:
   ```javascript
   let hasQuality = nbt.data.quality !== undefined || ['society:cheese_press', ...].includes(block.id);
   ```
   При переработке молока любого качества (серебряного, золотого, иридиевого) готовый сыр наследует тег `{quality_food:{quality: N}}`.
2. **Улучшение Розовой материей:**
   Если станок улучшен Розовой материей (`society:pink_matter`), при переработке Большого молока (`society:large_*_milk`) станок сразу выдаёт выдержанный сыр (`society:aged_*`), минуя выдержку в бочке.

### Б. Автоматический пресс (`meadow:cheese_form`)
1. **Сычужный фермент (`meadow:rennet`):**
   - В оригинале квеста фигурирует как `Rennet` (Сычужный фермент).
   - Крафтится в кулинарном котелке (`meadow:cooking`): `1x Яйцо` + `1x Соль` + `1x Бутылка воды` $\rightarrow$ `2x Сычужный фермент`.
   - Без сычужного фермента автоматический пресс не начинает цикл створаживания.
2. **Инвентарь и воронки:**
   В коде класса `CheeseFormBlockEntity` реализован интерфейс `WorldlyContainer`:
   - Верхняя сторона (`Direction.UP`): загрузка ведра молока и сычуга.
   - Нижняя сторона (`Direction.DOWN`): забор готовой головки сыра и пустого ведра.
3. **Отсутствие качества:** Мод Meadow не интегрирован с системой `quality_food`, поэтому на выходе всегда получается стандартный сыр нулевого качества.

## 3. Выводы по геймплейному назначению

* **`society:cheese_press` (Ремесленный пресс):** Станок для **ручного штучного крафта элитного сыра**. Требует участия игрока, но сохраняет высокое качество сырья (что критично для последующей выдержки в бочках и дорогой продажи в Shipping Bin).
* **`meadow:cheese_form` (Автоматический пресс):** Промышленная машина для **автоматизированных фабрик и пассивного дохода**. Работает медленнее (90 сек против 20 сек) и требует сычуг, но не требует участия игрока и перерабатывает сырьё непрерывно воронками.

## 4. Предложения по дифференциации названий

1. **Вариант 1 (Стандартный по квестам FTB — Рекомендуемый):**
   * `block.society.cheese_press` $\rightarrow$ **Ремесленный пресс для сыра** *(англ. Artisan Cheese Press)*
   * `block.meadow.cheese_form` $\rightarrow$ **Автоматический пресс для сыра** *(англ. Auto-Cheese Press)*

2. **Вариант 2 (По функциональному признаку):**
   * `block.society.cheese_press` $\rightarrow$ **Ручной пресс для сыра**
   * `block.meadow.cheese_form` $\rightarrow$ **Сыроваренная форма** *(буквальный перевод Cheese Form)*

3. **Вариант 3 (Ремесло vs Механизация):**
   * `block.society.cheese_press` $\rightarrow$ **Пресс сыродела**
   * `block.meadow.cheese_form` $\rightarrow$ **Механический пресс для сыра**
