# Задача: Доработка подсказок для Аппарата для создания семян (society:seed_maker)

## 📌 Цель
Добавить понятный и подробный тултип (включая раскрывающийся блок по `[Shift]`) для Аппарата для создания семян (`society:seed_maker`), объясняющий:
1. Возможность получения семян со звёздным качеством и их влияние на урожай.
2. Механику выбора минимального качества при смешивании плодов разного уровня (например, 2 золотых + 1 обычный $\rightarrow$ обычные семена).
3. Возможность улучшения Древней шестернёй (`society:ancient_cog`) с 5% шансом выпадения семян Древнего плода.
