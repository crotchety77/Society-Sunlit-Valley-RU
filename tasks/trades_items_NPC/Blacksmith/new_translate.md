# Согласование перевода: Товары Кузнеца (Blacksmith Trades)

## Блок 1: Визуальный макет в игре

### 1. Верстак мебели (`refurbished_furniture:workbench`)
```
&fВерстак мебели
&7Позволяет выгодно создавать мебель и декор из каталога
```

### 2. Статуя Лунного гнома (`society:moon_statue`)
```
&fСтатуя Лунного гнома
&7Дает случайное благословение добычи полезных ископаемых раз в день при нажатии

Сообщения в чате при активации:
&dБлагословение дня:
&f+1 дополнительная сырая руда при добыче.
&fДополнительный шанс при поиске жеод.
&fВалуны имеют 15% шанс раскрыть расположение ближайших верёвок в радиусе 8 блоков.
&fШанс 5% найти Тайник сокровищ в руде.
&fШанс 5% нанести 100 урона мобам в Пещере Черепа при атаке.
```

### 3. Малое и Большое ядра молота (`justhammers:small_core`, `justhammers:impact_core`)
```
&fМалое ядро
&7Используется для создания молотов с областью добычи 3x3x1

&fБольшое ядро
&7Используется для создания молотов с областью добычи 3x3x3
```
