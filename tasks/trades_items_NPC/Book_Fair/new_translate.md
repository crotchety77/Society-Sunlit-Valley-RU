# Согласование перевода: Книжная ярмарка (Book Fair Trades)

## Блок 1: Визуальный макет в игре

### 1. Подпись магазина в телефоне
```
&fМагазины
&fЯрмарка книг
&7Предлагает особые книги навыков в зависимости от сезона. Можно вызвать по телефону в конце сезона (20-30 числа).
```

### 2. Книги Мастерств (требуют открытия соответствующего навыка в меню K)
```
&fБлагодатная почва
&7[Мастерство фермерства]

&fПлюшевый бум лабубум
&7[Мастерство животноводства]

&fБойня номер пруд
&7[Мастерство рыболовства]

&fИ рождается искра
&7[Мастерство шахтёрства]

&fКрасное или чёрное
&7[Мастерство приключений]
```

### 3. Сезонные книги (продаются только в соответствующий сезон 20–30 числа)
```
&fФеноменальные сокровища &8(Весна, 20-30)
&fПотомки скажут спасибо &8(Весна, 20-30)

&fРайский урожай &8(Лето, 20-30)
&fЛягушачья ярмарка щедрости &8(Лето, 20-30)

&fБить сильно и нежно &8(Осень, 20-30)
&fКанадский и знаменитый &8(Осень, 20-30)
&fПрорастание &8(Осень, 20-30)

&fСинежаберный меридиан &8(Зима, 20-30)
&fДобыча свинца без последствий &8(Зима, 20-30)
```
