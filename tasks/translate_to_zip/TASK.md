## Задача: сформировать актуальный пакет русского перевода из текущей сборки игры

У меня есть исходный архив русского перевода, который был сделан другим переводчиком. Я изначально скопировал этот архив в свою сборку игры, а затем уже непосредственно в установленной игре дополнял и изменял перевод.

Таким образом, текущий перевод в моей сборке содержит две части:

```text
Исходный архив другого переводчика
        ↓
Скопирован в игру
        ↓
Мои дополнительные переводы и исправления
        ↓
Текущая версия файлов в установленной сборке
```

Проблема в том, что исходный архив больше не является актуальным. За время работы я изменил и дополнил файлы непосредственно в папке игры. Сейчас необходимо сформировать **новый чистый пакет перевода**, который можно будет передать другим пользователям.

### Главный принцип

**Текущие файлы перевода в установленной игре являются источником истины.**

Необходимо взять актуальное состояние перевода из игры и на его основе сформировать отдельную папку, которую пользователь сможет просто скопировать в свою сборку.

Старый архив переводчика использовать только для сравнения и определения происхождения файлов. Не нужно автоматически считать его содержимое актуальным.

### Что необходимо сделать

Сначала исследуй структуру исходного архива перевода @Scriptora_Society.Sunlit.Valley.4.0.4 (1) и текущей папки перевода в установленной игре.

Определи, какие файлы присутствовали в исходном архиве, какие файлы были изменены мной, какие были добавлены мной позднее и какие файлы больше не нужны.

После этого сформируй новую директорию распространения, содержащую **актуальный перевод из текущей игры**.

При формировании новой папки необходимо сохранить структуру директорий и относительные пути файлов, чтобы пользователь мог просто скопировать содержимое этой папки поверх соответствующей директории своей сборки.

Например:

```text
Моя текущая игра
└── kubejs/
    └── assets/
        └── ...
            └── файлы перевода
```

должна превратиться в отдельный пакет:

```text
Русификатор/
└── kubejs/
    └── assets/
        └── ...
            └── файлы перевода
```

При этом структура внутри пакета должна соответствовать структуре, необходимой для установки перевода.

### Важное ограничение

Не редактируй содержимое перевода только ради формирования пакета.

Если в текущей игре текст переведён именно так — считай это актуальной версией.

Не откатывай мои изменения к версии первого переводчика.

Не заменяй мои переводы содержимым старого архива.

Не удаляй файлы только потому, что их не было в первоначальном архиве.

Сначала необходимо определить, действительно ли файл является частью текущего перевода и нужен ли он для его работы.

### Проверка различий

Для каждого файла, который отличается между старым архивом и текущей игрой, определи:

```text
Файл
Есть в старом архиве: да/нет
Есть в текущей игре: да/нет
Изменён после установки: да/нет
Добавлен мной: да/нет
Нужно включить в новый пакет: да/нет
Причина
```

Особое внимание удели файлам, которые были созданы нами непосредственно во время работы над переводом.

### Проверка полноты

После формирования нового пакета проведи обратную проверку:

если взять чистую установку сборки соответствующей версии и скопировать туда новый пакет, результат должен максимально соответствовать текущему переводу в моей рабочей игре.

Проверь, что:

```text
текущая игра
≈
чистая сборка
+
новый пакет перевода
```

При этом не нужно включать в пакет файлы, которые относятся к самой игре, модам, настройкам, сохранениям или другим изменениям, не являющимся частью перевода.

Если обнаружишь файлы, которые одновременно содержат перевод и другие изменения, отдельно отметь их. Такие файлы нельзя бездумно включать в распространяемый русификатор, поскольку вместе с переводом пользователям могут случайно передаться мои локальные изменения.

### Финальный результат

В итоге необходимо получить:

```text
Русификатор/
├── [полная необходимая структура директорий]
├── [актуальные файлы перевода]
└── ...
```

Это должна быть готовая папка для передачи другим пользователям.

После создания папки выведи отчёт:

```text
Количество файлов в исходном архиве:
Количество файлов в текущем переводе:
Количество новых файлов:
Количество изменённых файлов:
Количество удалённых/неиспользуемых файлов:
Количество файлов, которые нельзя безопасно распространять:
```

Отдельно перечисли файлы, которые требуют ручной проверки.

Главная цель: **не восстановить старый архив, а извлечь из моей текущей игры полноценную актуальную версию моего перевода и превратить её в самостоятельный пакет, который другой пользователь сможет просто скопировать в свою сборку.**
