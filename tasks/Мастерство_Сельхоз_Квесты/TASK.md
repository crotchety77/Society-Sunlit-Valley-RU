## Задача: проверить цепочку получения ресурсов и дополнить описания

Проведи аудит предметов и квестов, связанных с получением **ивового бревна** и ресурсов, необходимых для его получения.

Главная проблема: игрок видит в рецепте или квесте, что ему нужно **ивовое бревно**, а затем может узнать, что для его получения требуется **сборщик смолы**, который нужно установить и ждать около **7 игровых дней**. Однако из интерфейса неочевидно, **откуда вообще взять ивовое бревно и как получить саженец ивы**.

Необходимо пройти всю цепочку получения ресурса назад до первого доступного шага:

**ивовое бревно → способ получения → саженец ивы → способ получения саженца ивы → саженец мрачного дерева → способ получения саженца мрачного дерева → исходный способ получения.**

Для каждого звена проверь исходные файлы модов, KubeJS-скрипты, рецепты, loot tables, конфигурации и FTB Quests. Не делай выводы только по названию предмета или тексту квеста.

Особенно проверь:

* где и как получается **ивовое бревно**;
* нужен ли для этого **саженец ивы**;
* как получается **саженец ивы**;
* действительно ли для получения саженца ивы требуется **саженец мрачного дерева**;
* как получается **саженец мрачного дерева**;
* действительно ли он может выпасть при сборе различных культур/растений;
* из каких именно культур он может выпасть;
* какой именно шанс выпадения используется в коде;
* если процент нигде явно не указан, определить вероятность по исходной механике/формуле, если это возможно;
* есть ли другие способы получения саженца мрачного дерева.

### Что нужно изменить

Если на каком-либо этапе игроку не хватает информации для понимания следующего шага, добавить короткое понятное описание в подходящий предмет, квест или другой доступный игроку текст.

Описание должно объяснять именно **способ получения**, а не просто повторять название предмета.

Например, если игрок видит ивовое бревно, он должен из описания понять примерно следующее:

> Для получения ивового бревна потребуется саженец ивы. После выращивания дерева его можно использовать для получения древесины.

Если для получения саженца ивы требуется саженец мрачного дерева, это тоже должно быть указано.

Если саженец мрачного дерева получается случайно при сборе культур, указать этот факт. Если точный шанс удалось установить по коду — указать процент. Если процент невозможно достоверно определить, **не придумывать его**, а написать, что саженец имеет небольшой шанс появиться при сборе культур.

### Важный принцип

Игрок не должен попадать в ситуацию:

**«Мне нужно ивовое бревно → где его взять?»**

и не должен останавливаться на этапе:

**«Нужен саженец ивы → где взять саженец ивы?»**

После прочтения описаний должна быть понятна вся цепочка получения ресурса вплоть до первого доступного способа.

При этом не нужно перегружать каждое описание всей цепочкой. Разнеси информацию по предметам/квестам так, чтобы каждый следующий шаг логично подсказывал игроку, куда двигаться дальше.

### Результат аудита

В конце составь отчёт:

**Предмет/квест → текущая проблема → что игрок не может понять → что нужно добавить → итоговый текст описания.**

Отдельно укажи:

1. точный источник каждой механики;
2. точный шанс получения саженца мрачного дерева, если его удалось определить;
3. какие описания были добавлены или изменены;
4. какие места всё ещё требуют ручной проверки.

Не изменяй механику игры. Задача — только обнаружить информационные пробелы и дополнить локализацию/описания там, где игроку не хватает информации.
