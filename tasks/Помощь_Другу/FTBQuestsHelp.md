# ❓ FTB Quests: Исходный текст в .snbt против Языковых Ключей

---

## 🛑 1. Почему в сборке Cisco's нет «ключей» и почему ломались квесты?

В сборке **Cisco's Fantasy Medieval RPG** автор создавал квесты через стандартный визуальный редактор FTB Quests. 
Весь английский текст автор вводил напрямую в поля редактора:

```snbt
title: "Searching for Supplies"
subtitle: "Adventure through Time"
description: [
    "&9Knowledge &fkeeps you alive."
]
```

Когда друг скачал и закинул «русик» из интернета:
1. Чужой русификатор просто перезаписал файлы `.snbt` версией от старого обновления сборки.
2. В новом обновлении автор сборки поменял внутренние `id` квестов, добавил новые цепочки и награды.
3. Из-за полной замены файлов игра потеряла актуальную структуру квестов, а прогресс и зависимости сломались.

## 🛠️ 2. Два подхода к переводу FTB Quests

---

### 🟢 Подход 1: Прямой перевод внутри файлов `.snbt` (Рекомендуется для ручного перевода)

Это самый простой и быстрый путь для человека, который переводит сборку сам без сложных скриптов.

#### Как это работает:
Ты открываешь оригинальный актуальный `.snbt` файл из папки сборки `config/ftbquests/quests/chapters/` в текстовом редакторе (VS Code / Notepad++) и заменяешь английский текст на русский внутри кавычек:

```snbt
title: "Поиск припасов"
subtitle: "Путешествие сквозь время"
description: [
    "&9Знания &fсохраняют жизнь."
]
```

#### Плюсы:
* ⚡ **Простота и скорость**: Не нужно ничего настраивать, придумывать ключи и создавать дополнительные файлы.
* 🔄 **Мгновенное применение**: Сохранил файл $\rightarrow$ в игре нажал **`F3 + T`** и ввёл **/ftbquests reload** $\rightarrow$ перевод сразу виден.

#### Минусы:
* 🌐 Нет переключения языков: квесты будут на русском даже если в настройках клиента стоит английский язык.

#### 🛡️ Главные правила безопасности при Подходе 1:
1. **Всегда делать бэкап**: Перед редактированием скопировать папку `chapters` (или файл `.snbt` $\rightarrow$ `.snbt.bak`).
2. **Не трогать служебные строки**:
   - ❌ `id: "0C7C5F4FF6A7BCA4"`
   - ❌ `tasks: [...]`
   - ❌ `rewards: [...]`
   - ❌ `dependencies: [...]`
3. **Не ломать кавычки и скобки**: Все скобки `[` `]`, `{` `}` и кавычки должны оставаться парными.
4. **Кодировка**: Всегда сохранять в **`UTF-8`**.

---

### 🔵 Подход 2: Перевод через Языковые Ключи (Локализация)

Это профессиональный метод, используемый в мультиязычных сборках.

#### Как это работает:
1. В файле `.snbt` вместо прямого текста прописывается ключ локализации в фигурных скобках:
   ```snbt
   title: "{cisco.quest.supplies.title}"
   subtitle: "{cisco.quest.supplies.subtitle}"
   description: [
       "{cisco.quest.supplies.desc1}"
   ]
   ```
2. Сам текст квестов выносится в языковой JSON-файл:
   `kubejs/assets/cisco_quests/lang/ru_ru.json`:
   ```json
   {
     "cisco.quest.supplies.title": "Поиск припасов",
     "cisco.quest.supplies.subtitle": "Путешествие сквозь время",
     "cisco.quest.supplies.desc1": "&9Знания &fсохраняют жизнь."
   }
   ```
   И аналогично создаётся `en_us.json` для английского языка.

#### Плюсы:
* 🌍 Поддержка мультиязычности: при переключении языка в настройках игры квесты автоматически меняют язык.
* 📦 Разделение данных: файлы `.snbt` содержат только логику, а весь текст хранится в одном месте в JSON.

#### Минусы для ручного труда:
* ⌛ Очень трудоёмко вручную: в сборке 21 глава и сотни квестов. Для каждой фразы придётся вручную придумывать уникальный ключ, заменять строку в `.snbt` и прописывать её в `.json`. Обычно это делают специальными скриптами (FTB Quest Localizer / Python).

---

## 🎯 Итоговая рекомендация

* Если цель — **быстро и качественно перевести сборку для себя или друзей**: используйте **Подход 1** (аккуратный перевод исходных строк в актуальных `.snbt` файлах сборки).
* Главное — **никогда не перезаписывать `.snbt` чужими готовыми файлами из интернета от других версий сборки**.
