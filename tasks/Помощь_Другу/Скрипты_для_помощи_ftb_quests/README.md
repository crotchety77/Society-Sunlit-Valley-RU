# 🛠️ Набор инструментов для удобного перевода FTB Quests

Этот набор скриптов избавляет от необходимости вручную ковыряться в техническом коде `.snbt`. Он позволяет переводить квесты в обычных текстовых файлах, а затем в 1 клик безопасно вставляет перевод обратно в игру с автоматическими резервными копиями (`.bak`).

---

## 🗂️ Содержимое папки

* **`export_quests.py`** — скрипт **экспорта**: выгружает все квесты из файлов сборки `.snbt` в простые текстовые файлы `.txt`.
* **`import_quests.py`** — скрипт **импорта**: считывает ваш перевод из `.txt` и аккуратно вставляет его в `.snbt` сборки.
* **`chapters_to_translate/`** — папка, где лежат текстовые файлы каждой главы квестов.

---

## 🚀 Пошаговая инструкция: Как переводить квесты

### Шаг 1. Экспорт квестов в текст (уже выполнен!)
Если сборка обновилась или нужно перевыгрузить тексты:
1. Запустите скрипт:
   ```bash
   python export_quests.py
   ```
2. В папке `chapters_to_translate/` появятся файлы для каждой главы (например, `age_of_dragons.txt`, `the_squires_trials.txt`...).

---

### Шаг 2. Перевод в текстовом редакторе
1. Откройте любой файл из папки `chapters_to_translate/` в **VS Code** или **Notepad++**.
2. Внутри вы увидите понятные блоки каждого квеста:

```text
=== [КВЕСТ 1 | ID: 4B4BF1FF89C31ACA] ===
EN_TITLE: 
RU_TITLE: Бестиарий

EN_SUBTITLE: Prudent Preparation
RU_SUBTITLE: Разумная подготовка

EN_DESCRIPTION:
&9Knowledge &fkeeps you alive.

&aA Bestiary &fcontains information about most of the &1magical &fcreatures you may encounter possibly granting you a combat advantage.

&2The manuscripts &fyou will need can be found within chests in caves , dragon roosts or graveyards.

RU_DESCRIPTION:
&9Знания &fсохраняют жизнь.

&aБестиарий &fсодержит сведения о большинстве &1магических существ&f, с которыми вы можете столкнуться, давая вам преимущество в бою.

&2Рукописи&f, необходимые для его заполнения, можно найти в сундуках в пещерах, логовах драконов или на кладбищах.

--- КОНЕЦ КВЕСТА 4B4BF1FF89C31ACA ---
```

3. **Что нужно делать**:
   * Пишите русский перевод в полях `RU_TITLE:`, `RU_SUBTITLE:`, `RU_DESCRIPTION:`.
   * Цветовые коды (`&6`, `&a`, `&9`, `&f`, `&2`) можно оставлять или менять по вкусу.
   * Если поле `RU_` оставить пустым — в игре останется оригинальный английский текст.

---

### Шаг 3. Импорт перевода в игру (1 клик)
Когда перевели квесты и сохранили `.txt`:
1. Запустите скрипт импорта:
   ```bash
   python import_quests.py
   ```
2. Скрипт:
   * Автоматически создаст резервную копию каждого файла главы (`<глава>.snbt.bak`).
   * Безопасно обновит только текст квестов по их уникальным ID.
   * Проверит, что ни один квест или награда не потерялись.

---

### Шаг 4. Проверка в игре
1. Откройте Minecraft.
2. Нажмите **`F3 + T`** (перезагрузка ресурсов).
3. Введите команду в чат: **/ftbquests reload** (или перезагрузите мир).
4. Откройте книгу квестов — ваш перевод на месте!

---

## 🛡️ Безопасность
* Скрипт **никогда не стирает** задачи (`tasks`), награды (`rewards`) или зависимости (`dependencies`).
* Перед любой записью всегда создаётся резервная копия `.snbt.bak`.
* Если скрипт заметит несоответствие количества квестов — он аварийно отменит запись.
