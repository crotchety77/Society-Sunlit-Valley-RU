## 🎨 Блок 1: Визуальные шаблоны (Как это выглядит в игре)

### 1. Подпись над головой NPC (Entity Name Tag)
```text
┌───────────────────────────────┐
│           Карлос              │  <-- dialog.npc.trader.name
│         [Сущность]            │
└───────────────────────────────┘
```

```text
┌───────────────────────────────┐
│        Библиотекарь           │  <-- weaponsmith (Librarian)
│         [Сущность]            │
└───────────────────────────────┘
```
