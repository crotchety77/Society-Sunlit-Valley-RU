# 📖 Инструкция по переводу диалогов NPC (Society: Sunlit Valley)

В этой папке находятся файлы со всеми диалогами персонажей игры.

---

## 🛠️ Как переводить

1. Откройте любой `.md` файл нужного персонажа (например, `01_carpenter.md`, `02_banker.md`).
2. В таблицах найдите колонку **«Перевод (RU)»** и впишите русский вариант:

| ID ключа | Оригинал (EN) | Перевод (RU) | Заметки редактора |
|---|---|---|---|
| `dialog.npc.carpenter.chatter_friendship0.0.line_0` | What can I help you with today @i? | Чем я могу помочь тебе сегодня, @i? | Доброжелательный тон |

3. В начале каждого файла приведено краткое **досье персонажа** (характер, манера речи, отношение к игроку).

---

## ⚠️ Важные правила форматирования

1. **Токен `@i` (Имя игрока):**  
   Если в оригинале есть `@i`, обязательно оставляйте `@i` на месте обращения к игроку по имени:  
   *EN:* `Hey @i, how's it going?` $\rightarrow$ *RU:* `Привет, @i, как дела?`
2. **Символ процента строго `%%`:**  
   В Minecraft одиночный знак `%` вызывает вылет игры! Если в диалоге есть проценты, пишите строго два знака: `10%%`, `50%%`.
3. **Цветовые коды `§`:**  
   Если используются цвета, пишите параграфы: `§6Золото§7`, `§aЗелёный§7`.

---

## 🚀 Как собрать итоговый файл `ru_ru.json`

После того как вы внесли перевод, просто **дважды кликните по файлу**:
👉 **`Собрать_Перевод.bat`** (или запустите `node compile.js` / `python compile.py`).

Скрипт:
1. Проверит все строки на ошибки (например, неэкранированные знаки `%`).
2. Создаст готовый файл **`ru_ru.json`** прямо в этой папке.
3. Если на вашем компьютере установлен модпак, он автоматически скопирует файл в:  
   `D:\ModrinthApp\profiles\Society_ Sunlit Valley\kubejs\assets\dialog\lang\ru_ru.json`.
