# База знаний: Дружба и подарки жителям (Villager Friendship)

В сборке действует механика отношений с жителями городка. Повышение дружбы открывает уникальные скидки, диалоги и ценные награды.

---

## 🎁 1. Основные правила взаимодействия

- **Вручение подарка:** Нажмите `Shift + ПКМ` по жителю, держа предмет в руке.
- **Кулдаун подарков:** 1 раз в **4 игровых дня**.
- **Ежедневный диалог:** Простой разговор с жителем приносит **+5 очков дружбы** каждый день.
- **Шкала дружбы:** **100 очков = 1 Сердце ♥** (максимум 500 очков / 5 сердец).

---

## ⭐ 2. Категории подарков и очки

| Категория | Очки дружбы | Описание |
| :--- | :---: | :--- |
| **Любимый (Loved)** | **+40** | Уникальные тематические предметы для конкретного жителя |
| **Нравится (Liked)** | **+25** | Качественная продукция, выпечка, самоцветы |
| **Нейтральный (Neutral)** | **+10** | Большинство базовых предметов с ценой продажи |
| **Не нравится (Disliked)** | **-15** | Неподходящие предметы, сорняки, сырьё |
| **Ненавидит (Hated)** | **-30** | Мусор, испорченные предметы, яды |

> 💡 *Полный список подарков для каждого конкретного жителя можно посмотреть в игре через JEI/EMI по тегу `#villager_gift`.*

---

## ✨ 3. Универсальные любимые подарки (+40 очков всем жителям)

Эти предметы гарантированно понравятся абсолютно любому жителю:
- 💎 **Призматический осколок** (*Prismatic Shard*)
- 🐇 **Кроличья лапка** (*Rabbit's Foot*)
- 🍵 **Чай Улун** (*Oolong Tea*)
- ☀️ **Солнечная жемчужина** (*Sun Pearl*)
- 🍷 **Желейное вино** (*Jelly Wine*)
- 🧙 **Гном** (*Gnome*)
- 🏺 **Чаша душ** (*Soul Vessel*)
- 🔮 **Блок жемчуга** (*Pearl Block*)

---

## 🏆 4. Награды при максимальной дружбе (5 Сердец ♥)

При достижении 5 сердец жители дарят эксклюзивные **Книги навыков Puffish Skills** и редкие артефакты:
- **Библиотекарь:** Книга навыка обучения / зачарования.
- **Торговец с Рынка:** Книга навыка торговли и выгоды.
- **Кузнец / Шахтёр:** Профессиональные чертежи и минералы.
